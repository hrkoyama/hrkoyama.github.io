Independent periodic He2 force reference / 周期He₂の独立した力の参照

DFTK 0.7.19, Julia 1.12.2; pinned Project.toml and Manifest.toml are supplied.
The reference is generated by a separate plane-wave Hamiltonian, SCF, Ewald
sum and analytic local-pseudopotential force implementation. It does not call
PySCF or reuse Gaussian orbitals or PySCF nuclear derivatives. Both programs
use Libxc for the same LDA_X + LDA_C_VWN (VWN5) functional formulas, so this is
not an independent derivation or verification of those XC formulas.

Model (identical in both engines): an artificial two-He neutral periodic cell,
four valence electrons, spin unpolarized, integer occupations, cubic lattice
5 bohr, Cartesian positions (0.37,0.61,0.83), (2.13,2.27,2.41) bohr.
This is an asymmetric force test, not a predicted equilibrium helium crystal.
The explicit local-only He GTH-PADE-q2 coefficients are copied exactly from
PySCF 2.11.0. There are no nonlocal projectors. Native neutral-cell Ewald and
native GTH G=0 corrections are included. No fitted energy/force offset, force
symmetrization or zero-net-force correction is applied.

He.gth records the exact local coefficients as numerical model input. The
DFTK PspHgh reader checks ionic charge, local range and coefficients, absence
of nonlocal channels, and hashes the file. GTH's generation approximation is
distinct from the explicit VWN5 XC pair used in these SCF runs.

Run from this directory after installing Julia and instantiating the pinned
reference environment:
  julia --project=reference-environment -e 'using Pkg; Pkg.instantiate()'
  JULIA_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1 julia \
    --project=reference-environment reference.jl inputs.json reference-new.json He.gth
The first JIT compilation can take substantially longer than an SCF solve.
MPI initialization may require permission to open a loopback socket even
for this serial-cell calculation. The reference is not regenerated by the
ordinary Python public runner.

The script uses the exact explicit Gamma-containing fractional meshes in
inputs.json with equal weights and no symmetry reduction. At Gamma and 2^3
it sweeps 90/120/180/240 hartree kinetic-energy cutoffs. This cutoff is the
orbital plane-wave basis, distinct from PySCF's Gaussian orbital basis and
FFT density-fitting grid. The SCF density tolerance is 1e-10, fixed occupied
bands are 1 and 2, and band 3 is additionally converged to diagnose a sampled
KS gap. The self-consistent solver uses SimpleMixing damping 0.6 with the
Anderson fixed-point solver, seed 1234, and six computed bands.

compute_forces_cart(scfres) returns analytic Cartesian forces in Eh/bohr,
including local-pseudopotential and ion-ion Ewald derivatives. At fixed cell,
a plane-wave basis does not move with the nuclei; this does not test Pulay
stress under varying cell shape/volume. The Gaussian calculation must include
basis-motion/overlap derivative terms. Each engine's energy finite difference
re-converges the electronic state at both displacements.

The independent reference checks all six Cartesian force components against
central energy differences at h=0.001 bohr. Atom 0, x additionally uses
h=0.01 and 0.005 bohr. All atom/component indices in reference JSON are zero
based. Energies and SCF diagnostics for every displaced solve are retained.
Force = -dE/dR; energy units are Eh/cell and force units Eh/bohr.

The acceptance limits are fixed in inputs.json: last-cutoff force increment
<1e-5 Eh/bohr, last-cutoff energy increment <1e-4 Eh/cell, and maximum analytic
versus central-energy-difference force discrepancy <1e-5 Eh/bohr. The finite
cutoff increments are empirical convergence evidence, not rigorous complete-
basis error bounds. Agreement with the Gaussian code is separately checked
at the identical finite k meshes. It does not make Gamma a converged k mesh,
validate other species, metals, stress, general nonlocal pseudopotentials,
or a long BOMD trajectory.
