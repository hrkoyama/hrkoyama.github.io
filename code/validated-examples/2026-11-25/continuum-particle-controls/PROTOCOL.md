# Fixed continuum and particle checks

This packet defines five scientific cases for four backlog candidates. The five common reference/metadata candidates are tracked in a separate migration proposal and are not five new numerical runs.

Run `python run.py --input inputs.json --output results` in a fresh directory. After the numerical run, run `python -m pytest -q test_components.py` for the separately identified component and wrong-formula controls. Plot only saved arrays with `python plot.py --results results/result.json --output results`. Plotting needs Matplotlib; the solver/reference/component checks use NumPy and pytest, with no SciPy import. Actual execution and acceptance outcomes are recorded in results/result.json and the verification receipt.

The Saltzman-type example explicitly uses Tan, Lv and Zhu (2023), Example 8, with specific internal energy 1e-4. Its mesh is prescribed affine ALE motion, not the source paper's WENO/material-Lagrangian method. Exact finite-pressure piston Rankine--Hugoniot states are averaged over actual quadrilateral cells. Moving-wall work and GCL have independent component controls.

Sphere transport is a limited Williamson-associated dimensionless scalar test. It does not solve nonlinear shallow water. The companion zonal-balance example advances an axisymmetric dimensionless shallow-water subproblem; it is not a complete global dynamical core. The original Williamson full PDF was not obtained; read limits and Nair--Côté--Staniforth (1999) formula crosschecks are explicit. The fixed protocol uses eleven noncommensurate exact-characteristic remaps on both grids: eleven genuine transport updates, not a one-step identity and not a time-convergence study. The fixed count limits repeated-interpolation diffusion while retaining eleven nontrivial transport updates. Bilinear interpolation is nonconservative and may be diffusive after one revolution; measured errors must satisfy the predeclared acceptance and are not assumed to pass.

GSPH here uses the actual Gaussian linear-specific-volume overlap and symmetric variable-h approximation of Inutsuka (2002), with first-order pair Riemann states and antisymmetric total-energy transfer. It is not ordinary SPH with star pressure substituted, and is not the paper's cubic-overlap/MUSCL implementation. SPH is a separate fixed-initial-h control. The Sod example is periodic with a second distant interface and a central observation window before outer waves arrive. Primitive values use particle m/rho quadrature, not finite-volume cell averages. Kernel initial-density differences are saved. Acoustic comparisons use a linearized model and disclose the finite-amplitude remainder.

Failed h solves retain their reason, iteration/residual and state arrays; the runner writes failure JSON/NPZ. No pressure/density floors, mesh repair, numerical clipping or automatic change of tolerances is authorized. Component tests contain wrong moving-mesh sign, omitted moving-wall work, wrong pair-energy sign, wrong backward-rotation direction and missing pole half-turn controls. Their tests are distinct from full PDE accuracy checks.

All gallery figures and CSV exports must be generated from the saved result arrays with English axis labels. No font installation is required. Runtime measurements and acceptance outcomes belong to the result and verification receipts. Public source must use portable relative paths and must not include private preparation/review records.

The fixed-input runner has a shared cooperative wall budget of 90 seconds, checked between small numerical steps, plus the existing outer verifier budget. No automatic retry changes the numerical protocol. Top-level result checks are keyed exactly by case IDs and records.csv contains finite actual per-profile metrics before any plotting.

Failure ownership keeps the true accepted step-start state distinct from each evaluated midpoint/final candidate, with explicit physical stage time. ALE mesh/Q, scalar/SWE state and particle state/h/mass are attached before propagation. Raw numerical failure arrays are written to NPZ before strict JSON; nonfinite diagnostic scalars receive explicit NONFINITE labels only in failure diagnostics, while successful scientific results remain strictly finite. Analytic continuous zonal-force cancellation and actual unequal-mass/unequal-h swapped GSPH pair force/energy symmetry are recorded runtime decisions at their declared 1e-12 limits, in addition to independent component tests. Forced midpoint/final, nonfinite persistence, ALE deadline and invalid-SWE controls are separate component controls; measured outcomes are retained in test and verification receipts.

For unit-sphere cosine-bell radius R and unit peak, direct integration gives M = pi*((1-cos(R))+(1+cos(R))/(1-(pi/R)^2)). The runner records this analytic mass and the initial spherical-grid quadrature difference separately from subsequent numerical mass drift. This is an observational reference crosscheck, with no extra acceptance threshold.
