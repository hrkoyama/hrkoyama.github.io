# Small quantum and coupled-dynamics examples

This packet contains six small model families and two saved-reference audits, arranged as seven examples. `cases.json`, `cards.json`, `THEORY.md` and `provenance.json` state the mathematical conventions and limits. Actual execution and reproduction status belongs to `verification.json` and `results/result.json`.

The examples cover a coupled two-state BO/CP-type model with one short nuclear OU trajectory; hydrogen/helium reference cards; box/oscillator eigenpairs; two minimal-basis H2 geometries; one three-center H3+ molecule; a saved periodic-He force audit; and a three-plane-wave nonlocal-projector/Fermi model. These do not certify general materials, correlated exact continuum chemistry, long first-principles MD or thermal equilibration. N=1.5 in the Fermi model is a mean occupation count, not an integer-particle canonical many-body ensemble.

The shared reproduction requirements pin NumPy2.0.2, SciPy1.14.1 and pytest8.3.5. The algorithms import NumPy and do not call SciPy or PySCF. Saved-result plotting additionally uses Matplotlib3.9.4. Use Python3.12 for the full three-pin reproduction environment and mandatory public Linux check. The source syntax remains compatible with Python3.9; that is separate from support for all three pinned packages. Record the actual environment of every run rather than relabeling it as the pinned environment.

The included `freeze.json` binds the 23 public source, documentation, dependency, input, criteria and stored-reference files by SHA256. Its review flags describe how that fixed release was checked, without requiring access to private review files. Private preparation manifests and review records are excluded. The runner validates the binding before calculating. Run `python -W error run.py --input inputs.json --output NEW_RESULTS_DIRECTORY`. An alternative release freeze can be supplied through `--freeze PATH`.

Use a new output directory for each run. The runner saves standard `result.json`, per-check `measurements.csv`, plus native matrices/eigenpairs, SCF candidates and trajectory checkpoints before derived diagnostics. It refuses to overwrite existing checkpoints. Solver exceptions preserve returned data that exist; internal library iterates that were never returned cannot be recovered. Original accuracy goals and first failures must remain visible.

Run `python plot.py --results NEW_RESULTS_DIRECTORY/result.json --output NEW_RESULTS_DIRECTORY` to create seven case-ID PNGs from saved values and analytic field evaluation, without rerunning SCF or eigensolves. `MPLCONFIGDIR` and `PYTHONPYCACHEPREFIX` can be set externally for local scratch storage. Tests are in `test_quantum_small.py`.

The atomic and periodic-He reference audits add **zero** simulations. They retain existing values and acceptance criteria. Independent mathematical/component checks, stored external-engine comparisons and fresh full physical calculations are separately identified in the source and results.

Small matrix, vector and bilinear products use explicit NumPy index contractions with `optimize=False`; callers supply any complex conjugation. The eigenpair, molecular and projector diagnostics use scaled Euclidean/Frobenius sums. This avoids dispatching these small contractions to a vendor BLAS while retaining strict warning handling. One saved-array diagnostic on macOS arm64 with NumPy2.0.2 and Accelerate observed finite matrix-product results agreeing with scalar sums despite floating-point warnings. This observation does not establish behavior for other library or platform versions. Scalar real, complex and noncontiguous equivalence checks supplement the unchanged physical acceptance criteria.
