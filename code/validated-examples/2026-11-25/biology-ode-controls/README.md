# Fixed educational numerical controls

This edition calls NumPy for scientific execution and Matplotlib for plotting. The standard public ZIP requirements retain the reviewed NumPy/SciPy/pytest pins; these authored solvers do not call SciPy. Actual local interpreter/library versions are recorded separately, rather than asserted to equal installed pins. The equations, fixed row matrix and caps are in `inputs.json`; mandatory component/reference checks and separate study goals are in `acceptance.json`. Original papers and software conventions have explicitly limited read scopes in `source-reading.json`.

The included `freeze.json` binds the public source, fixed inputs, acceptance criteria and reference definitions by SHA256. Its root/peer review fields describe the fixed release; reproducing it requires no private review files. Generated result directories and public packaging receipts are excluded from the source binding. The runner verifies this binding before and after calculation.

Use an existing compatible runtime; no installation is performed by these scripts. Set `OMP_NUM_THREADS=OPENBLAS_NUM_THREADS=MKL_NUM_THREADS=1`. Point `MPLCONFIGDIR`, `PYTHONPYCACHEPREFIX` and `TMPDIR` to an owned scratch directory. The scientific command is `python run.py --input inputs.json --output results --seconds 115`. The plotting command is `python plot.py --results results/result.json --output results`; it reads saved arrays only. Run the small component tests with `python -m pytest -q test_models.py`; their time and the main run share the external120s group deadline. The main runner has a115s owned deadline to reserve time for startup,tests and handled-failure checkpoints; this does not increase the shared allowance.

`passed` concerns the mandatory numerical/reference/reporting contract. Every original accuracy/statistical study target retains its actual true/false/unresolved outcome. A missed target is not converted to a success mask. Finite tolerance/modal/quadrature sensitivity is not a rigorous global error bound. Sampling bands have their stated ideal independent-replica scope and do not prove mixing or PRNG software coverage.

Every completed row has its own saved NPZ arrays. A caught cap/error writes the active owned state and an incomplete receipt,preserves completed rows and exits nonzero. A hard external SIGKILL cannot flush an unreturned temporary state;already saved completed-row files remain. Existing result directories are never overwritten. Gallery and diagnostic figures are derived from those saved numerical arrays; no decorative or simulated-data substitute is used.

Small products use explicit `einsum(optimize=False)` contractions and scaled norms. This responds to a recorded macOS arm64/NumPy2.0.2/Accelerate flag artifact on finite returned arrays; no production warning is filtered. Inputs,physical equations,conjugations,association,caps,rows,seeds and original scientific thresholds remain fixed. Component tests compare real/complex and strided/contiguous products with independent scalar fsum. Actual qualification and runtime still come from the execution receipts.
