# Steady multistage residual iteration

Run `python run.py --input inputs.json --output fresh-results`, then `python plot.py --results fresh-results/result.json --output fresh-results`. Plot input may also be the result directory. Scientific dependencies are the three exact requirements pins; rendering additionally uses Matplotlib 3.9.4. The fixed protocol is dimensionless. Main and pytest together share 120 seconds, including all numerical reference qualification; plotting is separate. No automatic retries or post-result threshold changes.

Inputs, acceptance, algorithm and reference scope are specified in `inputs.json`, `acceptance.json`, `cases.json`, `source-reading.json` and `DESIGN.md`. A passing public result requires the exact frozen input SHA and nonempty records, metrics and checks for every case. CSV rows are finite; unavailable state error for inconsistent pendulum controls is an empty cell in the explicitly labelled column, not NaN.

Raw paths are saved before later reference/error diagnostics. Ordinary exceptions retain the owned active candidate and completed path; a hard process kill cannot recover unwritten memory. No projection, clipping, floor, implicit fallback or altered time window is used. Pseudo-time in the steady example is not physical-time accuracy.

Stored official IDA values, where used, are approximate printed values from SUNDIALS v7.1.1; their rounding intervals do not bound true-solution error. No IDA program is compiled or executed here. Position-constrained pendulum equations are index three; the explicit underlying ODE and disclosed critical constraint-error extension are not general high-index solvers.

## Post-measurement study scope, revision R4

The first retained execution failed the original protocol. Its source, input, acceptance limits, measured values and FALSE decisions remain immutable in the first-attempt history. Full raw arrays, CSV, logs, JUnit and the original private traceback are retained by the author; the public history contains exact inert source text and a derived result summary, not a fabricated full traceback or a claim that omitted arrays are included.

All original numerical targets are still evaluated under unchanged `inputs.json` and `acceptance.json`. `original_target_results` and `original_target_summary` report their actual decisions. For the explicitly named study goals only, the new scope verifies faithful saved-array recomputation and reporting rather than requiring success. Every other original numerical condition remains mandatory and individually visible in `checks`. A rerun is never required to reproduce a FALSE mask: platform-specific rounding may change a study outcome. `passed` verifies this explicitly revised execution/reporting scope; it does not mean every original numerical accuracy target passed. This scope revision was made after observing the original failure.

The expanding steady control missed its absolute residual target while its normalized field discrepancy remained near binary64 rounding. Robertson’s fixed schedule missed four time-accuracy/refinement targets despite successful nonlinear solves, conservation and ODE/DAE agreement. These cases teach different error mechanisms; no grid, tolerance, time window or accuracy threshold was calibrated to convert the original failures into passes. The index-one and pendulum cases still require all their original numerical conditions.
