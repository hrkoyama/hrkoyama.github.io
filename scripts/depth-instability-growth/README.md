Small, actual nonlinear2D centered-flux/Heun vorticity and active-buoyancy computations. The two separately derived continuous Fourier–Galerkin linear IVPs are scoped references for tiny perturbations, not exact nonlinear flows.

Run `python -W error run.py --input inputs.json --output new-results` after installing the three pins. `python -m pytest -q` checks22algebra/operator/protocol cases. Plot with `python plot.py --results new-results/result.json --output new-results` and optional Matplotlib3.9.4. Every output directory must be fresh.

The domain is the periodic square[0,2pi]^2. Smooth steady bases are maintained by explicit body/scalar forcing. In RT density enters buoyancy only and maps as rho/rho0=1-b/g; no finite-Atwood full-density Euler or sharp-interface formula is used. Native centered velocity divergence and the five-point Poisson constraint are different diagnostic operators. The auxiliary vorticity is a five-point-Poisson unknown, not asserted bit-identical to a composed centered velocity curl.
