解く問題
区間上の関数の多項式表現、L2射影、要素積分。
採用した変種・範囲
重み1のLegendreモードと任意のL2直交規格化。NumPyのLegendre評価とGauss求積を使用。

使える条件

  • モード係数と節点値の違いや直交性を確かめるとき。
  • 滑らかな区間関数の射影や定係数アフィン要素の行列を作るとき。

  • 曲線写像・可変係数でも同じ少数求積点で厳密積分できると期待する場合。
  • 不連続点をまたぐGauss求積だけで高精度を保証したい場合。

前提・比較仕様

  • 参照区間 [−1,1]、重み1の内積を採用する。∫PⱼPₖdξ=2δⱼₖ/(2k+1)、orthonormal指定時は√((2k+1)/2)を掛ける。
  • degreeは0以上の整数。project_legendreはGauss求積で射影積分を近似するため、一般関数に対して求積誤差も残る。
  • element_matricesの厳密求積指定は定係数・アフィン写像下の多項式積を対象とし、p+1点Gaussを使う。

条件を記載: 規格化、重み、次数、Gauss求積を確認した。

境界条件: 基底の評価・射影自体は物理境界を課さない。端点の値や流束、隣接要素の接続は利用する離散化側が指定する。剛性行列の定数モードの零空間も自動で除かない。

この構成要素では対象外: 基底評価は物理境界の施行ではない。

単位系: ξと基底は無次元。長さLのアフィン区間ではJ=L/2で、質量行列にJ、勾配の剛性行列に1/Jを掛ける。展開係数は表す関数と同じ単位。

条件を記載: 参照区間とアフィンJacobianの尺度を明記した。

Element bases & approximation

Legendre modal basis / orthonormal scaling

Educational example / related code

Represent reference-interval functions in Legendre modes. The implementation tabulates P₀…Pₚ and derivatives, optionally normalizes them, and computes unweighted L2 projection and affine element matrices by Gauss quadrature.

Methods and code referenceCode, inputs and checksLearn by field

Other names: Legendre基底 / Legendre polynomials / ルジャンドル基底 / ルジャンドル多項式

Method-specific conditions and sources: 2026-11-22

Problem and adopted formulation

Problem
Polynomial representation, L2 projection and element integration on an interval.
Variant and scope
Unweighted Legendre modes with optional unit-L2 normalization, using NumPy Legendre evaluation and Gauss quadrature.

Use when

  • Examining modal coefficients versus nodal values and orthogonality.
  • Projecting smooth interval functions or constructing constant-coefficient affine element matrices.

Avoid or add further treatment when

  • Expecting the same low-order quadrature to remain exact with curved maps or variable coefficients.
  • Relying on unsplit Gauss quadrature across a jump for guaranteed high accuracy.

Read the chapter

Assumptions and comparison specification

  • The reference interval is [−1,1] with weight one: ∫PⱼPₖdξ=2δⱼₖ/(2k+1); orthonormal=True multiplies by √((2k+1)/2).
  • Degree is a nonnegative integer. project_legendre approximates projection integrals by Gauss quadrature, leaving quadrature error for general functions.
  • Exact element-matrix quadrature means p+1 Gauss points for polynomial products with constant coefficients and an affine map.

Specified: Checked normalization, weight, degree and Gauss quadrature.

Boundaries: Basis evaluation/projection imposes no physical boundary condition. Endpoint values/fluxes and interelement coupling belong to the consuming discretization; the constant stiffness nullspace is not removed automatically.

Not applicable to this component: Basis evaluation does not impose physical boundaries.

Units: ξ and basis values are dimensionless. On an affine interval of length L, J=L/2 scales mass by J and gradient stiffness by 1/J. Expansion coefficients share the represented function's units.

Specified: Specified reference coordinates and affine-Jacobian scaling.

Scope and remaining work

Educational tabulation for modest degrees, without high-degree stability/performance guarantees. Discontinuities limit single-polynomial approximation and quadrature. Do not confuse Chebyshev weights with the unit Legendre weight, or GLL quadrature's highest-mode mass with exact mass.

Specified: Specified degree, discontinuity and quadrature limits.
