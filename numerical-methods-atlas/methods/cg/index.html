線形・非線形解法

共役勾配法

教育用例・関連コードあり

実対称正定値な連立一次方程式を共役方向で反復的に解く。公開例は単位正方形・零Dirichlet Poisson方程式の五点差分を、行列を組み立てずに扱う前処理なしCG。

条件・文献の個別整理：2026-11-22

解く問題と採用形

解く問題
Poisson方程式の離散化などから得られる、実対称正定値系 Ax=b。
採用した変種・範囲
五点差分作用素を直接適用する前処理なしの線形CG。共通比較経路では各反復で真の残差を再計算する。

使える条件

  • SPDが分かっている離散系で、行列積だけから解を求めたいとき。
  • 同じ格子・右辺・真の残差基準で他のPoisson解法と比較するとき。

避ける条件・追加処理が必要な場合

  • 移流による非対称系、鞍点系、零空間を残した周期・Neumann系。
  • 反復回数だけで計算時間や連続解の精度を保証したい場合。

解説と位置付け

解説章を読む

前提・比較仕様

  • 作用素は実対称正定値で、右辺は有限。ここでは定係数の −Δu=f を一様正方格子で離散化する。
  • 内積は配列成分のEuclidean内積。既存実装の初期値は零で、前処理は用いない。
  • poisson_comparison.solve は再計算した真の相対残差を停止に使う。linear.poisson_2d は反復残差と tolerance×max(1,初期残差) を使う。

条件を記載: CGの再帰式、前処理の有無、二つの停止条件をコードで区別した。

境界条件: 代数解法としてのCGは境界を定めない。公開2次元Poisson例は [0,1]² の全辺で u=0 をゼロ埋め込みにより課す。

この構成要素では対象外: CGの固有要件ではない。公開例の零Dirichlet条件は別途明記した。

単位系: CG自体に固有の物理単位はない。公開Poisson例は長さ1の無次元座標で、次元を与えるなら [f]=[u]/[長さ]²。残差は格子体積で重み付けしない配列ノルム。

条件を記載: 単位正方形と配列ノルムの規約を明記した。

Linear & nonlinear solvers

Conjugate gradients

Educational example / related code

Solve real SPD linear systems by conjugate directions. The public example is unpreconditioned matrix-free CG for the five-point zero-Dirichlet Poisson operator on a unit square.

Method-specific conditions and sources: 2026-11-22

Problem and adopted formulation

Problem
Real SPD systems Ax=b, including a discrete Poisson equation.
Variant and scope
Unpreconditioned linear CG with a matrix-free five-point operator; the comparison path recomputes the true residual each iteration.

Use when

  • The discretized system is known to be SPD and a matrix-free solve is desired.
  • Comparing Poisson solvers on the same grid, forcing and true-residual criterion.

Avoid or add further treatment when

  • Nonsymmetric advection systems, saddle-point systems or periodic/Neumann systems with an untreated nullspace.
  • Claims about runtime or continuous-solution accuracy based only on iteration count.

Read the formulation

Read the chapter

Assumptions and comparison specification

  • The operator must be real SPD and the right-hand side finite; the example discretizes constant-coefficient −Δu=f on a uniform square grid.
  • Inner products are Euclidean array products; the current implementation starts from zero and has no preconditioner.
  • poisson_comparison.solve stops on a recomputed true relative residual; linear.poisson_2d uses a recurrence residual with tolerance×max(1,initial residual).

Specified: Inspected the CG recurrence, absence of preconditioning and two stopping rules.

Boundaries: CG itself supplies no physical boundary condition. The public 2D Poisson examples impose u=0 on every side of [0,1]² by zero padding.

Not applicable to this component: Not intrinsic to CG; the examples' zero-Dirichlet condition is separately stated.

Units: CG has no intrinsic physical unit. The public Poisson coordinates have unit dimensionless length; dimensionally [f]=[u]/[length]². Residual norms are unweighted array norms.

Specified: Specified the unit-square and array-norm conventions.

Scope and remaining work

Do not apply this variant directly to nonsymmetric, indefinite or singular systems. This CG example has no preconditioner, general sparse-matrix interface or pure-Neumann nullspace handling. A small residual does not certify discretization accuracy; rapid termination for one eigenmode is not a general performance result.

Specified: Limited the claim to the SPD requirement and existing examples.

Scope of this review

Inspected linear.poisson_2d, poisson_comparison.solve and existing tests for general-forcing discrete residuals, matched stopping criteria and the single-mode case; no rerun.
