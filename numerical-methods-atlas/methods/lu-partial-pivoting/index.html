Assumptions for this example

  • Real, square, nonsingular matrices from a small fixed set; row partial pivoting.

Boundaries: No physical boundary conditions apply to the algebraic matrices. The string has homogeneous Dirichlet endpoints.

Units: Dimensionless algebraic controls. The FEM string has unit length, tension and density.
