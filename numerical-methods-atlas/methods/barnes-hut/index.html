重力と長距離相互作用

Barnes–Hut八分木

教育用例・関連コードあり

孤立した3次元粒子の重力加速度をoctreeで近似する。公開例はG=1のPlummer軟化核に対し、質量単極子または同じ軟化核の完全な二次モーメント項を使い、直接和と比較する。

別名・表記：Barnes Hut / Barnes-Hut法 / バーンズ・ハット法 / Barnes Hut tree / BH tree

条件・文献の個別整理：2026-11-22

解く問題と採用形

解く問題
正質量粒子の孤立・Plummer軟化Newton重力加速度。
採用した変種・範囲
Barnes–Hut octree、幾何開角s/d、単極子または軟化核の完全二次モーメント。theta=0で全て開く。

使える条件

  • 孤立境界で静的な力と開角・近似次数の関係を調べるとき。
  • 同じ位置・質量・軟化長で直接和と照合するとき。

避ける条件・追加処理が必要な場合

  • 周期系を孤立直接和とそのまま比較したい場合。
  • 近接衝突の非軟化力や厳密な対称相互作用を必要とする場合。

解説と位置付け

解説章を読む

前提・比較仕様

  • 位置は有限の(N,3)配列、質量は正かつ有限、粒子数は1以上。softening=ε>0、theta≥0、orderは0または2。
  • 節点の一辺s=2×half、質量中心までの距離dについて s/d<theta なら受理する。ただし対象粒子を含むセルは必ず開き、葉では自己項を除く。
  • 加速度核は −m r/(r²+ε²)^(3/2)。order=2はS=Σmδδᵀの完全なTaylor項を加え、軟化された核に必要なtrace(S)項も保持する。

条件を記載: 粒子入力、Plummer核、受理基準と二次項をコードで確認した。

境界条件: 孤立境界で周期像を加えない。軟化核のポテンシャル −Gm/√(r²+ε²) は無限遠で零となる規約。周期PM・Ewald・TreePMとは異なる境界問題。

条件を記載: 周期像なしの孤立直接和とtreeを同じ核で比較する。

単位系: 無次元のG=1。位置と軟化長は同じ長さ単位、質量には一貫した単位を使う。長さL₀・質量M₀で次元を戻す場合、加速度の尺度はGM₀/L₀²。

条件を記載: G=1と位置・質量・軟化の共通規約を固定例でも確認した。

Particle fields & gravity

Barnes–Hut octree

Educational example / related code

Approximate isolated 3D particle gravity with an octree. The public example uses G=1 and a Plummer-softened kernel, with a monopole or the same kernel's full second-moment term, compared with direct summation.

Methods and code referenceCode, inputs and checksLearn by field

Other names: Barnes Hut / Barnes-Hut法 / バーンズ・ハット法 / Barnes Hut tree / BH tree

Method-specific conditions and sources: 2026-11-22

Problem and adopted formulation

Problem
Isolated Plummer-softened Newtonian acceleration from positive-mass particles.
Variant and scope
Barnes–Hut octree with geometric s/d opening, monopole or full softened second moment; theta=0 fully opens the tree.

Use when

  • Studying static isolated-force error versus opening angle and expansion order.
  • Comparing against direct summation with identical positions, masses and softening.

Avoid or add further treatment when

  • Direct comparison of a periodic problem to isolated direct summation.
  • Unsoftened close encounters or strictly symmetric pair interactions.

Read the formulation

Read the chapter

Assumptions and comparison specification

  • Positions are finite (N,3), masses positive and finite, and N≥1; ε=softening>0, theta≥0 and order is 0 or 2.
  • A node is accepted when s/d<theta, with s=2×half and d measured to its center of mass. Target-containing cells are always opened; leaves exclude self terms.
  • The acceleration kernel is −m r/(r²+ε²)^(3/2). order=2 adds the full Taylor term from S=Σmδδᵀ, retaining trace(S) for the softened kernel.

Specified: Checked particle inputs, Plummer kernel, acceptance and second-order term in code.

Boundaries: Isolated boundaries without periodic images; the softened potential −Gm/√(r²+ε²) tends to zero at infinity. This is a different boundary problem from periodic PM, Ewald or TreePM.

Specified: The tree and isolated direct sum use the same kernel without periodic images.

Units: Dimensionless G=1. Positions and softening share a length unit and masses use one consistent unit. With scales L₀,M₀, acceleration is restored with GM₀/L₀².

Specified: Checked G=1 and common position/mass/softening conventions in the fixed example.

Scope and remaining work

A static-force educational example without time integration, expansion, periodic images or FMM. theta is not a rigorous error bound, and order=2 need not improve every configuration. Targetwise approximation does not guarantee exact action–reaction/total-momentum conservation. Interaction counts are not timings or empirical complexity guarantees for every distribution.

Specified: Scoped to static cases and targetwise approximation.
