この例の前提

  • 採用係数は1/4,1/3,1/2,1で、各段階の基準値は同じです。
  • 固定した16成分の周期線形系で残差・モード振幅・位相を測ります。

境界条件: 固定例は周期格子で、周期差分を全段階に適用します。

Assumptions for this example

  • The selected coefficients are 1/4, 1/3, 1/2 and 1; all stages share the same base state.
  • Residuals, modal amplitudes and phase are measured on a fixed 16-component periodic linear system.

Boundaries: The fixed example applies periodic differences at every stage.

Units: The product of pseudo-time step and operator eigenvalue is dimensionless; physical-time accuracy is a separate question.

Small dedicated implementations and measured checks

Additional fixed examples: Real-space mode damping with steady multistage RK. See each release for assumptions and checked scope. Scope and remaining work

The chosen stability polynomial matches classical RK4 on linear problems, but this is not a fourth-order method for general nonlinear problems. Stable modes, a neutral control and an expanding control are distinguished.
