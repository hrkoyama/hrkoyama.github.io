線形・非線形解法

Armijo減衰Newton法

教育用例・関連コードあり

非線形方程式 F(x)=0 を、Jacobianから求めたNewton方向と残差ノルムの十分減少による減衰で解く。公開例は密行列解法または前処理付きGMRESの内部解法を選べる。

条件・文献の個別整理：2026-11-22

解く問題と採用形

解く問題
微分可能な平方の非線形連立方程式 F(x)=0。
採用した変種・範囲
残差ノルムのArmijo型十分減少を用いる減衰Newton。内部線形解法はdenseまたはGMRESで、Jacobianは明示指定。

使える条件

  • Jacobianを与えられ、根の候補に近い初期値があるとき。
  • 非線形問題で線形解法の誤差と減衰の作用を分けて確認するとき。

避ける条件・追加処理が必要な場合

  • Jacobianが特異になる点や、解が複数ある問題を初期値依存なしに解きたい場合。
  • 制約付き最適化やJacobianなしの巨大問題をこのまま解く場合。

解説と位置付け

解説章を読む

前提・比較仕様

  • FとJacobianを利用者が与える。平方の微分可能な系と、解の近くで非特異なJacobianが基本となる。
  • 長さ1から1/2ずつ減らし、||F(x+αs)||₂ ≤ (1−10⁻⁴α)||F(x)||₂ を要求する。α<2⁻²⁰で失敗を返す。
  • GMRES経路でもJacobianは明示的に与える。CSRならILU(0)、それ以外ならJacobi前処理を使い、内部残差と外部絶対残差を区別する。

条件を記載: 受理不等式、半減、Jacobianと内部解法を確認した。

境界条件: Newton法自体に物理境界はない。境界はFとJacobianの組立て側が指定する。既存Bratu検査は [0,1] の両端零Dirichletを内部未知数の残差へ組み込む。

この構成要素では対象外: 境界は残差とJacobianの定義に属する。

単位系: 固有の物理単位はなく、未知数・残差の尺度は呼び出し側が決める。単位・桁の違う残差成分を自動で無次元化しないため、ノルムと絶対許容誤差を使う前に尺度を揃える。

条件を記載: ソルバーによる尺度変換はなく絶対ノルムを使う。

Linear & nonlinear solvers

Armijo-damped Newton

Educational example / related code

Solve F(x)=0 using a Jacobian-based Newton direction and damping that requires sufficient decrease of the residual norm. The example supports a dense or preconditioned GMRES inner solve.

Method mapCode, inputs and checksReading chapters

Other names: Newton法 / ニュートン法 / Newton method / damped Newton / 減衰Newton法 / Armijo Newton

Method-specific conditions and sources: 2026-11-22

Problem and adopted formulation

Problem
A differentiable square nonlinear system F(x)=0.
Variant and scope
Damped Newton with an Armijo-type residual-norm decrease test; explicit Jacobian and dense/GMRES inner solve.

Use when

  • A Jacobian and an initial guess near a candidate root are available.
  • Examining the separate effects of inner linear accuracy and damping.

Avoid or add further treatment when

  • Requiring initial-guess-independent results near singular Jacobians or multiple roots.
  • Direct use for constrained optimization or very large Jacobian-free problems.

Read the formulation

Read the chapter

Assumptions and comparison specification

  • The caller supplies F and its Jacobian; the basic setting is a square differentiable system with a nonsingular Jacobian near the root.
  • Starting at one, the step is halved until ||F(x+αs)||₂ ≤ (1−10⁻⁴α)||F(x)||₂; failure is returned below α=2⁻²⁰.
  • The GMRES path still uses an explicitly supplied Jacobian; CSR uses ILU(0), otherwise Jacobi preconditioning. Inner and outer absolute residual criteria differ.

Specified: Inspected the acceptance inequality, halving, Jacobian and inner solvers.

Boundaries: Newton has no intrinsic physical boundary. F/Jacobian assembly supplies it; the existing Bratu test encodes zero Dirichlet values at both ends of [0,1].

Not applicable to this component: Boundaries belong to the supplied residual/Jacobian.

Units: No intrinsic physical unit; the caller defines unknown and residual scales. Components are not nondimensionalized automatically, so scale them consistently before using the norm and absolute tolerance.

Specified: No automatic scaling; the solver uses an absolute norm.

Scope and remaining work

Convergence depends on the initial guess, Jacobian nonsingularity and residual scaling; global convergence is not guaranteed. Singular dense solves or preconditioner construction may raise exceptions rather than return a failure reason. No matrix-free Jv, trust region or continuation is provided.

Specified: Distinguished returned failures from exception paths.
