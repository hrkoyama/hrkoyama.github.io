解く問題と採用形

解く問題
滑らかな波と衝撃波を併せ持つ1次元Euler流の空間流束微分。
採用した変種・範囲
reconstruction.pyのweno-z: p=2のWENO-Z重み、点値FD、大域LF分割、界面固定特性基底（既定）、SSPRK3。

使える条件

  • 一様格子上で滑らかな解の高次空間精度と不連続の捕獲を比較したい。
  • 点値とセル平均を区別し、ε・CFL・特性投影の選択を管理できる。

避ける条件・追加処理が必要な場合

  • 一般の非構造格子や多次元、保証付きの真空処理が必要。
  • セル平均を入力する有限体積WENOと、この点値FD実装を同一視して使いたい。

解説と位置付け

解説章を読む

前提・比較仕様

  • 対象は1次元・一様Cartesian格子の理想気体Eulerで、各段階に有限かつ正の密度・圧力を要する。
  • qはセル平均ではなく点値。大域波速a=max|u±c|でf±=(f±a q)/2に分け、正負の流束に逆向きの5点ステンシルを使う。
  • 重みはd=(0.1,0.6,0.3)、Jiang–Shuのβ_k、τ_5=|β_0−β_2|、α_k=d_k[1+(τ_5/(ε+β_k))²]。既定ε=10^-6。
  • 既定は界面で固定したRoe特性基底で両流束を投影し、成分別も選べる。時間積分はSSPRK(3,3)、入力CFLは0<CFL≤0.5。

条件を記載: weno_left・weno_flux・solve_eulerの係数と表現を確認。

境界条件: reconstruction._padで周期、端点初期値固定、または端値外挿のゴースト値を使う。境界での一様な高次精度や無反射性は保証しない。

条件を記載: 同モジュールのゴースト値分岐を確認。

単位系: 公開例は無次元Euler量。一般の単位を使う場合、βとτは投影した流束の2乗の尺度を持つため、固定ε=10^-6の効果も変わる。状態・流束の無次元化または尺度に合うεを検討する。Δt・Δx・波速の単位は整合させる。

条件を記載: βとτの式、固定εから尺度依存性を明記。

適用範囲と残る作業

5次は滑らかな領域での空間精度であり、時間は3次。不連続近傍で同じ次数は期待できず、ε・尺度・基底の影響を受ける。段階で非正値になると時間刻みを半減して再試行するが、これは正値性の定理ではない。WENO分岐はHLLCを使わず、有限体積PPM/MUSCL用の正値再構成スケーリングも使わない。

Method-specific conditions and sources: 2026-11-22

Problem and adopted formulation

Problem
Approximate spatial flux derivatives for one-dimensional Euler flows containing both smooth waves and shocks.
Variant and scope
weno-z in reconstruction.py: p=2 WENO-Z weights, pointwise FD, global LF splitting, face-frozen characteristic projection by default, and SSPRK3.

Use when

  • Compare smooth-solution high-order spatial accuracy with discontinuity capture on a uniform grid.
  • Point values and cell averages can be distinguished, and ε, CFL and characteristic projection can be controlled.

Avoid or add further treatment when

  • General unstructured meshes, multiple dimensions or guaranteed vacuum treatment are required.
  • A finite-volume WENO accepting cell averages is required instead of this pointwise FD implementation.

Read the formulation

Read the chapter

Assumptions and comparison specification

  • The scope is one-dimensional perfect-gas Euler on a uniform Cartesian grid, with finite positive density and pressure at each stage.
  • q contains point values, not cell averages. A global a=max|u±c| splits f±=(f±a q)/2; oppositely biased five-point stencils reconstruct the two fluxes.
  • Weights use d=(0.1,0.6,0.3), Jiang–Shu β_k, τ_5=|β_0−β_2| and α_k=d_k[1+(τ_5/(ε+β_k))²], with default ε=10^-6.
  • Both split fluxes use the same face-frozen Roe characteristic basis by default; component reconstruction is optional. Time integration is SSPRK(3,3), with 0<CFL≤0.5.

Specified: Inspected coefficients and data representation in weno_left, weno_flux and solve_euler.

Boundaries: reconstruction._pad uses periodic ghosts, fixed initial endpoint states or edge extrapolation. Uniform high-order boundary accuracy and nonreflection are not guaranteed.

Specified: Inspected the module's ghost-state branches.

Units: Released Euler examples are nondimensional. With dimensional data, β and τ scale as the squared projected flux, so the effect of a fixed ε=10^-6 changes with scaling. Nondimensionalize states/fluxes or choose a scale-consistent ε. Use compatible units for Δt, Δx and wave speed.

Specified: Scaling dependence follows from β/τ formulae and the fixed ε.

Shared input, execution, validation and citation steps

Scope and remaining work

Fifth order refers to smooth-region spatial accuracy; time accuracy is third order. The same order is not expected near discontinuities, and ε, scaling and basis matter. Invalid stages trigger step halving and retries, which do not constitute a positivity theorem. The WENO branch uses neither HLLC nor the positive-reconstruction scaling used by the finite-volume PPM/MUSCL branch.

Specified: Separates FD/FV, spatial/time order and retry logic/positivity guarantees.

Scope of this review

Read weno_left, weno_flux, euler_eigenbasis and solve_euler in reconstruction.py. Inspected existing tests for smooth flux-derivative order, constant states, periodic totals, Sod/moving contacts and eigenbasis inversion. No numerical rerun was performed.
