レベルセット法

教育用例・関連コードあり

界面をφ=0で表し、Hamilton–Jacobi型の方程式で移流・法線運動を扱う。専用の2D円の平行移動・偏心剛体回転をENO2＋Heunで検証し、面積誤差と再初期化の影響を比較する。

Level-set method

Educational example / related code

Represent an interface by phi=0 and evolve advection or normal motion through Hamilton–Jacobi equations. Dedicated ENO2/Heun examples validate 2D circle translation and off-center rigid rotation, measuring area error and redistancing effects.

Assumptions for this example

  • Prescribed sufficiently regular velocity and resolved interface. Dedicated examples use a fixed unit square, analytic exterior data and rigid circle kinematics.

Boundaries: Dedicated level-set examples prescribe analytic exterior ghost data at every RK stage; no periodic or general two-phase-flow validation.

Units: Examples are nondimensional. A distance-like phi has length units in dimensional formulations; a volume fraction is dimensionless.

Small dedicated implementations and measured checks
