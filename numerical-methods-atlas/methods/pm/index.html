重力と長距離相互作用

FFT粒子格子力

教育用例・関連コードあり

周期3次元粒子の質量をCICで格子へ割り当て、平均密度を除いたPoisson方程式をFFTで解き、格子加速度を同じCICで粒子へ戻す。公開例は連続Fourier記号 −4πG/k² とスペクトル微分を使う。

手法・コードの対応表コード・入力・検証分野別に解説を読む

別名・表記：PM法 / particle mesh / 粒子格子法 / particle mesh method

条件・文献の個別整理：2026-11-22

解く問題と採用形

解く問題
平均密度を差し引いた、周期粒子系の格子上重力Poisson問題と粒子加速度。
採用した変種・範囲
8点CIC割当て/補間、連続k²記号のFFT Poisson、k=0固定、スペクトル加速度。

使える条件

  • 周期系で粒子と格子の結合、質量保存、零モードを調べるとき。
  • 単一Fourierモードにより重力の符号・ゲージを確かめるとき。

避ける条件・追加処理が必要な場合

  • 孤立境界や格子以下の近接力をこのまま必要とする場合。
  • この例をEwald/PME/SPMEの誤差制御付き置換とみなす場合。

解説と位置付け

解説章を読む

前提・比較仕様

  • 立方体の周期箱、正かつ有限の粒子質量、有限位置、立方n³格子でn≥4、L>0を使う。位置は各軸でLを法として折り返す。
  • CICは8隅への積線形重みで密度を作り、格子体積で割る。粒子へ戻す補間も同じ重み。CIC窓の逆補正は行わない。
  • ∇²φ=4πG(ρ−平均ρ)、φ̂(0)=0。非零モードは −4πG/k²、加速度は−∇φ。偶数格子の微分は各軸の対応Nyquistモードを零にして実の奇作用素を保つ。

条件を記載: CIC、Green関数、重力符号、零・Nyquistモードをコードで確認した。

境界条件: 全方向周期、箱長L。平均密度を除くことで周期Poissonの整合性を満たし、k=0を零に固定してポテンシャルの加法定数を選ぶ。孤立境界の力とは同一問題でない。

条件を記載: 周期折返し・平均除去・ポテンシャルのゲージを確認した。

単位系: pm_accelerationはG=1固定の無次元例。L・位置には同じ長さ単位を使い、ρは質量/L³、φはGM/L、加速度はGM/L²に対応する。下位関数periodic_poissonのみ正のgravityを指定できる。

条件を記載: 上位G=1と下位gravity指定を区別した。

Particle fields & gravity

FFT particle–mesh forces

Educational example / related code

Deposit periodic 3D particle mass by CIC, FFT-solve Poisson after removing mean density, and interpolate acceleration back with matched CIC. The example uses the continuum Fourier symbol −4πG/k² and spectral derivatives.

Methods and code referenceCode, inputs and checksLearn by field

Other names: PM法 / particle mesh / 粒子格子法 / particle mesh method

Method-specific conditions and sources: 2026-11-22

Problem and adopted formulation

Problem
Periodic particle gravity through the mesh Poisson problem for density contrast.
Variant and scope
Eight-vertex CIC deposition/interpolation, FFT Poisson with continuum k², fixed zero mode and spectral acceleration.

Use when

  • Studying particle/mesh coupling, mass conservation and the zero mode in a periodic system.
  • Checking gravitational sign and gauge with a single Fourier mode.

Avoid or add further treatment when

  • Direct use for isolated boundaries or accurately resolved subgrid pair forces.
  • Treating this example as an error-controlled Ewald/PME/SPME substitute.

Read the formulation

Read the chapter

Assumptions and comparison specification

  • A cubic periodic box, positive finite particle masses, finite positions, cubic n³ mesh with n≥4 and L>0; coordinates wrap modulo L in every axis.
  • CIC deposits to eight vertices with product-linear weights divided by cell volume; interpolation uses the same weights. No CIC-window deconvolution is applied.
  • ∇²φ=4πG(ρ−meanρ), with φ̂(0)=0. Nonzero modes use −4πG/k² and acceleration is −∇φ. On even meshes, each derivative zeroes its own-axis Nyquist mode to retain a real odd operator.

Specified: Checked CIC, Green function, gravitational sign and zero/Nyquist modes in code.

Boundaries: Periodic in all directions with box length L. Mean removal enforces periodic-Poisson compatibility, while zeroing k=0 fixes the additive potential gauge. This is not the isolated-force problem.

Specified: Checked periodic wrapping, mean removal and potential gauge.

Units: pm_acceleration is a dimensionless G=1 example. L and positions share a length unit; density, potential and acceleration scale as M/L³, GM/L and GM/L². Only the lower-level periodic_poisson accepts a positive gravity parameter.

Specified: Distinguished top-level G=1 from lower-level gravity selection.

Scope and remaining work

A static PM-only example without direct short-range correction. CIC smoothing, grid anisotropy, aliasing and finite resolution remain; the continuum Fourier Green function is not the inverse symbol of a finite-difference Laplacian. No P3M, TreePM split, Ewald, PME/SPME, expansion or time integration is included.

Specified: Specified PM-only static scope and finite grid resolution.
