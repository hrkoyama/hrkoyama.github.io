時間積分

速度Verlet／粒子leapfrog法

教育用例・関連コードあり

位置だけに依存する力を、半分のkick・drift・半分のkickで進める2次の可逆・シンプレクティック法。公開例は単位質量の調和/四次振動子で、エネルギー誤差と構造保存が同じでないことを確かめる。

解く問題と採用形

解く問題
位置依存ポテンシャルを持つHamilton系の軌道と長時間の幾何学的挙動。
採用した変種・範囲
hamiltonian._verletのkick–drift–kick（velocity-Verlet形）。公開の対象は単位質量の1次元調和・四次振動子で、Verlet原報の位置漸化式とは表現を区別する。

使える条件

  • 固定刻みで、分離Hamiltonianの可逆性・シンプレクティック性とエネルギー誤差を比較したい。
  • 位置依存力の時間尺度を解像できる振動子の教材例が欲しい。

避ける条件・追加処理が必要な場合

  • 速度依存力や摩擦、拘束を追加しても同じ構造保存が自動的に成り立つと期待する。
  • 任意質量・多粒子系や適応刻みの汎用実装を必要とする。

解説と位置付け

解説章を読む

前提・比較仕様

  • 公開例は1自由度、単位質量の自律・分離Hamiltonian H(q,p)=p²/2+V(q)。V=q²/2またはq²/2+q⁴/4。
  • 力は−V'(q)で位置のみに依存する。p_half=p−h V'(q)/2、q_new=q+h p_half、p_new=p_half−h V'(q_new)/2を用いる。
  • 可逆性とシンプレクティック性の説明は固定刻みの同じ写像に対するもの。精度と安定性のため力学的時間尺度を解像する。

条件を記載: _gradient・_verletと選択できる2ポテンシャルを確認。

境界条件: この振動子の位相空間写像に空間境界条件は該当しない。原報の周期Lennard–Jones流体とは別の問題であり、粒子の周期境界や壁・拘束はこの実装にない。

この構成要素では対象外: 有限次元の振動子写像で境界の入力はない。

単位系: 公開振動子は質量m=1、調和角振動数ω=1に無次元化している。一般の質量に転用する場合はdriftをh p/mとし、q・p・力・時間の尺度を整合させる必要があるが、その一般化はこの公開関数の入力では提供しない。

条件を記載: driftの係数1とポテンシャルからm=ω=1の尺度を明示。

適用範囲と残る作業

元のHamiltonianを各ステップで厳密保存するわけではない。シンプレクティックでも大刻みは不安定になり得て、ω=1の調和振動子では|h|<2が安定域の内部。速度依存力、摩擦・サーモスタット、拘束、一般の可変刻みや非分離Hamiltonianでは、同じ性質をそのまま保証できない。公開関数は一般分子動力学solverではない。

条件を記載: エネルギー誤差、写像の構造、刻みの安定性を分離。

Time integration

Velocity Verlet / particle leapfrog

Educational example / related code

A second-order reversible symplectic method using half kick, drift and half kick for position-dependent forces. Released unit-mass harmonic/quartic oscillators illustrate why energy error and geometric structure preservation are different properties.

Methods and code referenceCode, inputs and checksLearn by field

Other names: Verlet法 / ベルレ法 / 速度ベルレ法 / velocity Verlet / particle leapfrog

Method-specific conditions and sources: 2026-11-22

Problem and adopted formulation

Problem
Trajectories and long-time geometric behaviour of Hamiltonian systems with a position-dependent potential.
Variant and scope
Kick–drift–kick (velocity-Verlet form) in hamiltonian._verlet, restricted to unit-mass one-dimensional harmonic/quartic oscillators; distinguished from the original paper's position recurrence.

Use when

  • Compare fixed-step reversibility/symplecticity with energy error for a separable Hamiltonian.
  • An oscillator teaching example with resolved position-dependent-force time scales is useful.

Avoid or add further treatment when

  • The same geometric guarantees are expected to survive added velocity forces, friction or constraints automatically.
  • A general-mass, many-particle or adaptive-step implementation is required.

Assumptions and comparison specification

  • The released example is an autonomous separable one-degree-of-freedom Hamiltonian H(q,p)=p²/2+V(q) with unit mass and V=q²/2 or q²/2+q⁴/4.
  • The force is −V'(q), depending only on position. The update is p_half=p−h V'(q)/2, q_new=q+h p_half, p_new=p_half−h V'(q_new)/2.
  • Reversibility and symplecticity refer to the same fixed-step map. Dynamical time scales must still be resolved for accuracy and stability.

Specified: Inspected _gradient, _verlet and both supported potentials.

Boundaries: Spatial boundary conditions do not apply to this oscillator phase-space map. It is a different problem from the original periodic Lennard-Jones fluid; particle periodicity, walls and constraints are not implemented here.

Not applicable to this component: The finite-dimensional oscillator map has no boundary input.

Units: The released oscillator is nondimensional with m=1 and harmonic ω=1. A general-mass formulation would require drift h p/m and consistent position, momentum, force and time scales; that generalization is not an input feature of this released function.

Specified: Unit mass/frequency follow from the drift coefficient and potential.

Scope and remaining work

The original Hamiltonian is not exactly preserved at each step. A symplectic map can still be unstable at large steps; for the ω=1 harmonic oscillator, |h|<2 is the interior stability interval. Velocity-dependent forces, friction/thermostats, constraints, generic variable steps and nonseparable Hamiltonians require different treatment. This function is not a general molecular-dynamics solver.

Specified: Separates energy error, map geometry and step stability.

Scope of this review

Read _gradient, _verlet, canonical_step and trajectory in hamiltonian.py. Inspected existing tests for second-order convergence, the Jacobian symplectic condition, time reversal, non-exact original energy conservation and large-step instability. No rerun was performed.
