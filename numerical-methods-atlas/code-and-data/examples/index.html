  • Barnes–Hut：192粒子と直接和の比較

  • 周期PM粒子群：質量・内力・格子場

    入力・実行・判定へ →

  • 周期Taylor–Green渦：速度・散逸・発散

  • He：閉殻HF・交換のみLDA

    入力・実行・判定へ →

  • ロジスティック増殖：解析解と刻み幅の収束

    無次元の単一個体群。RK4を全出力時刻で解析解と比較し、非負性と刻み幅の収束を確認。反応拡散・複数種は対象外。

    入力・実行・判定へ →

  • SIR：独立DOP853参照・人口保存・収束

    閉鎖・均質な人口割合SIR。RK4と別実装のSciPy DOP853を比較。人口保存・非負性・時間収束を確認。SEIR・空間伝播・実データ較正は対象外。

    入力・実行・判定へ →

  • Monte Carlo：256 seedの積分誤差と区間被覆

    U[0,1]でx²を積分。256の独立seedで解析積分・分散と比較し、Nの平方根に反比例するRMS誤差と区間被覆を確認。MCMC・希少事象は対象外。

    入力・実行・判定へ →

  • Itô SDE：共有Brown運動による強収束

    スカラー幾何Brown運動のEuler–Maruyama。粗細刻みと解析解で同じBrown運動を共有し、4096経路で強RMS誤差を測定。一般SDE・MCMC・弱収束次数は検証しない。

    入力・実行・判定へ →
