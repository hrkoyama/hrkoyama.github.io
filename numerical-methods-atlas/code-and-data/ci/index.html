何を確認するか・運用の条件

現在の対象は22問題、共有を除く21コマンド、7つの配布ZIPです。

水素型原子とHeは同じ1回の実行を共有し、各問題の条件を別々に判定します。Heは保存済みの有限基底PySCF参照と比較します。

  1. 公開配布物の取得・ハッシュ照合
  2. 新規環境への依存導入
  3. 固定入力の計算
  4. 数値条件と出力の判定

取得・導入・実行・数値判定のどこで止まったかを記録します。計算が未実行の場合は、数値条件の不合格と区別します。失敗時のログとJSONもActionsのartifactに残します。

固定入力と記載した数値公差を判定します。ZIP／入力をハッシュで照合し、再計算CSV／画像のバイト一致は求めません。配布版pytest全件、全67問題、独立PySCF／DFTK参照の再生成は別の確認です。周期Heは保存済みDFTK参照と比較します。 多原子He₂の力とBOMD局所接続は同梱DFTK参照で判定し、長時間MDを保証しません。

Verification scope and operation

The current scope is 22 problems, 21 distinct commands and 7 distribution ZIPs.

Hydrogenic atoms and helium share one execution and receive separate numerical decisions. Helium is compared with the saved finite-basis PySCF reference.

  1. Public download and hash checks
  2. Fresh-environment dependency installation
  3. Fixed-input execution
  4. Numerical acceptance and output checks

The record distinguishes download, setup, execution and numerical-validation failures. An unrun calculation is separate from failed numerical acceptance. Failure logs and JSON are also retained as Actions artifacts.

Evaluate fixed inputs against stated numerical tolerances and check ZIP/input hashes, without requiring byte-identical rerun CSV/images. Full packaged pytest suites, all 67 problems and regeneration of independent PySCF/DFTK references are separate checks. Periodic He is compared against its saved DFTK reference. Multiatom-He₂ forces and the local BOMD interface use the saved DFTK reference; long MD trajectories are not certified.
