残差・条件数・後退誤差

到達目標：問題の敏感さと解法の安定性を分け、小さい残差だけでは正確な解を保証しないと理解する。

連立方程式を解いて「残差は小さい」と表示されても、解が正確とは限らない。残差は方程式への当てはまり、解の誤差は基準解からの距離だからである。

問題の入力が少し変わったとき、解がどれほど変わりやすいかを表すのが条件数である。問題の敏感さと、解法が余計な誤差を作るかというアルゴリズムの性質を分けよう。

誤差と残差を式で結ぶ

正則なAに対してAx=bを解き、近似解をx̂とする。残差をr=b-Ax̂と定めると、A(x-x̂)=rである。逆行列の作用が大きければ、小さな残差も大きな解の誤差に対応する。

条件数と後退誤差

同じ誘導行列ノルムでκ(A)=||A|| ||A⁻¹||と定義する。後退誤差は「どれほど小さく入力を変えれば、計算した値が厳密解になるか」を測る。後退安定な解法でも、条件の悪い問題の前進誤差を一律に小さくはできない。

PDEではもう一段ある

線形方程式の解の誤差が小さくなっても、その方程式は連続PDEの近似にすぎない。代数残差と離散化誤差を別々に調べ、必要以上に反復だけを細かくしない。

小さな計算例

Aの二つの行をほぼ同じにすると、入力の小さな差で解が変わりやすくなる。A=[[1,1],[1,1+ε]]、ε=10⁻⁴とし、真の解を(1,1)に選ぶ。

右辺の第2成分へδ=10⁻⁶を加えた問題の解は(1-δ/ε,1+δ/ε)となる。元の問題への相対残差は約5×10⁻⁷だが、相対解誤差は約10⁻²である。

eps, delta = 1.0e-4, 1.0e-6
xhat = [1-delta/eps, 1+delta/eps]
b = [2.0, 2.0+eps]
r = [2.0-xhat[0]-xhat[1],
     b[1]-xhat[0]-(1+eps)*xhat[1]]
print(xhat, r)

この行列の∞条件数は約4.0×10⁴。コードではDecimalによる高精度の解析式とも照合する。ここで示すのは入力感度の例であり、あらゆる線形ソルバーの評価ではない。

確認問題と解答

問1　残差を10倍小さくすれば、PDEの全誤差も必ず10分の1になるか。

解答を開く

ならない。条件数による増幅と、空間・時間の離散化誤差が残る。

問2　条件数が大きいことは、実装が間違っている証拠か。

解答を開く

問題そのものが敏感である可能性がある。解法の後退誤差と区別して調べる。

つまずきやすい点

  • 異なる行列ノルムの条件数を混ぜない。
  • 不定性のある純Neumann行列へ正則行列の式をそのまま使わない。

この章の要点

  • 残差は方程式への当てはまり。
  • 解の誤差には問題の敏感さが関わる。
