安定性・収束とLaxの同値定理

到達目標：適切に設定された線形初期値問題と整合する線形近似を対象に、決めたノルムでの一様な安定性と収束の関係を読む。

正しい微分方程式を近似する式でも、入力した小さな誤差を激しく増幅すれば、解は基準へ近づかない。整合性と安定性をつなぐことで、初めて収束を論じられる。

ここでのLax-Richtmyerの同値定理は、適切に設定された線形初期値問題と、それに整合する線形近似を対象にする。「どんな数値計算にも、整合性さえあればよい」という定理ではない。

有限時間で一様に抑える

離散解を進める行列をB_hとし、決めた有限時間Tまで考える。初期誤差を増幅するB_hの累乗が、格子幅や刻みに依存しない定数で抑えられることが重要である。どのノルムを使うかも定義の一部になる。

誤差は局所欠陥の積み重ね

符号を含む1刻みの欠陥をδと置くと、誤差の漸化式を繰り返して次の式を得る。安定なら、それぞれの欠陥はC_T倍までしか増幅されない。欠陥がΔt×ε(h,Δt)で抑えられ、εが消えれば、有限時間の誤差も消える。

同値定理の読み方

適切な線形問題と整合する線形近似という枠組みで、安定性と収束は同値になる。上の評価は安定性から収束へ向かう要点で、逆向きの厳密な証明には関数空間等の設定が要る。非線形保存則や不連続解に、そのまま適用してはいけない。

小さな計算例

中心空間差分と前進Eulerによる移流FTCSは、滑らかな解に対して整合的である。しかし固定Courant数の下で一部の格子波数を増幅する。

格子幅を小さくすると、同じ物理時間までに必要なステップ数も増える。1刻みの増幅が固定で1を超えるモードは、その累乗で抑えられなくなる。

from math import sqrt
nu = 0.6
G_abs = sqrt(1+nu*nu)  # theta=pi/2
for n in [10, 20, 30]:
    print(n, G_abs**n)

保存した診断ではCFLを満たすFTCSも増幅する。これは意図した不安定例が検出できたという成功であり、FTCSを安定な移流法として合格させた意味ではない。

確認問題と解答

問1　安定性の定数がhを細かくするほど際限なく大きくてもよいか。

解答を開く

Lax-Richtmyerの意味ではいけない。有限時間Tで、刻みに依存しない評価が必要になる。

問2　この定理だけで衝撃波を含む非線形問題の収束を主張できるか。

解答を開く

できない。問題・解・離散化のクラスが異なり、別の解析が必要になる。

つまずきやすい点

  • 固定行列で固有値を眺めるだけで、全格子系列の一様安定性を結論しない。
  • 少数の実験を定理の証明と呼ばない。

この章の要点

  • 整合性と安定性を組にして考える。
  • ノルム・有限時間・一様性を明示する。
