von NeumannのFourier安定性解析

到達目標：定係数・一様格子・周期または無限領域を基本として、波数ごとの増幅率を調べる。

周期的な正弦波を入れたとき、差分法が振幅と位相をどう変えるかを調べる。定係数・一様格子の線形差分では、Fourierモードごとに計算を分解できる。これがvon Neumann解析である。

ここでのNeumannは人名であり、後で学ぶ法線微分を指定するNeumann境界条件と同じ計算手順ではない。有限領域の境界処理は、Fourier解析とは別に確認する必要がある。

一つのモードを代入する

格子上の複素モードexp(i jθ)を差分式へ入れる。線形で係数が一定なら、次時刻も同じ形になり、複素数Gだけが掛かる。実際の実数の波はモードの実部・虚部の組で表せる。 ここでiはi²=-1を満たす虚数単位で、exp(i jθ)=cos(jθ)+i sin(jθ)である。複素数を使うと、正弦波と余弦波の二つを一度に扱える。

風上法とLax-Wendroff法

速度a>0、Courant数ν=aΔt/hの移流を考える。θは連続波数kに対するkhである。低波数だけでなく、格子が表せる範囲全体を調べる。

|G|と偏角の役割

スカラーの周期問題では、全モードで|G|≤1なら離散L2は増えない。これは有用な十分条件である。Lax型の一様安定性には1+CΔtのような増幅を許す評価もあり、|G|がわずかに1を超えるという観察だけを万能の不安定判定にはしない。偏角は位相の誤差を表し、第11章で調べる。

小さな計算例

配布コードでは、解析的なGだけでなく、複素Fourier配列を実際の差分更新で1刻み進めた結果も照合する。式の導出と実装の符号を、別の経路で確認するためである。

Courant数0.6のFTCSでは、θ=π/2で|G|=√(1+0.6²)>1となる。この倍率が固定のままステップ数が増えるため、固定した物理時間で一様な安定性が壊れる。

from cmath import exp
from math import pi
nu, theta = 0.6, pi/2
g_up = 1-nu+nu*exp(-1j*theta)
print(abs(g_up), g_up.real, g_up.imag)

symbols.csvには波数ごとの振幅と位相・群速度がある。実装のモード更新と解析式の差は、固定した絶対基準1e-12以下を要求する。

確認問題と解答

問1　長い波だけ調べて安定性を結論してよいか。

解答を開く

よくない。短い格子波長のモードが不安定な場合がある。

問2　有限領域の境界がある場合も、内部差分の|G|だけで十分か。

解答を開く

一般には十分でない。境界を含む行列やエネルギー評価、実際の境界例を別に確認する。

つまずきやすい点

  • 変係数・非線形・非一様格子へ無条件に拡張しない。
  • 複数成分や非正規性のある系では固有値以外も考える。

この章の要点

  • モードを実際の差分へ代入する。
  • 振幅と位相を分けて読む。
