初期条件とDirichlet・Neumann・Robin条件

到達目標：値を与える、外向き法線微分を与える、両者を組み合わせる、という境界条件の意味を読む。

微分方程式だけでは、求める解は一つに決まらない。時間の始めの状態が初期条件、空間の端での制約が境界条件である。どちらもモデルの一部であり、計算を始める都合だけで選んではいけない。

Poissonのような楕円型問題と、移流のように情報が出入りする問題では、必要な境界条件が異なる。特に移流では、流入側へ何を与えるかが重要になる。

三つの基本形

Dirichletは値、Neumannは外向き法線微分、Robinはその線形結合を指定する。Neumannを物理流束として与えるときは、拡散係数と符号を含めた関係を明示する。たとえば拡散流束は通常-κ∂_nuである。 式中のg_D、g_N、g_Rは、それぞれDirichlet、Neumann、Robinの指定値を表す。

外向き法線の向き

区間[0,1]では左端の法線は-1、右端は+1である。従って左の∂_nuは-u′(0)、右はu′(1)になる。両端に同じ+x方向の微分を入れると、境界流束の収支が変わってしまう。

条件は方程式と組で考える

時間依存問題では、初期値と境界値が端で整合しているかも大切である。不整合があると初期の層や非滑らかさが生まれ、滑らかな解に対する次数の予想がそのまま現れない。周期境界は端どうしを結ぶ別の条件である。

小さな計算例

-u″=fに厳密解を先に選び、そこから右辺と境界値を作る。Dirichlet例はsin(πx)+0.3x+1、Neumann例はcos(2πx)、Robin例はexp(x)とする。

これは同じfのまま境界条件だけを替えた比較ではなく、それぞれの境界型を確かめる別の製造解である。問題の定義を変えたときは、参照も対応させる。

from math import exp
alpha, beta = 2.0, 1.0
u_left, ux_left = 1.0, 1.0
u_right, ux_right = exp(1), exp(1)
g_left = alpha*u_left-beta*ux_left
g_right = alpha*u_right+beta*ux_right
print(g_left, g_right)

Robin例ではg_left=1、g_right=3eとなる。符号の確認だけでも、境界処理の大きな間違いを防げる。

確認問題と解答

問1　左端の外向き法線微分は+u′(0)か。

解答を開く

違う。区間[0,1]では-u′(0)である。

問2　Neumann条件が常に「流束そのもの」を意味するか。

解答を開く

一般には違う。物理流束との間には符号や係数が入る。定義を確認する。

つまずきやすい点

  • 楕円型の境界条件を移流へ無条件に持ち込まない。
  • 初期値・境界値の不整合を数値法の故障と即断しない。

この章の要点

  • 境界条件も問題の一部。
  • 法線と流束の符号を明記する。
