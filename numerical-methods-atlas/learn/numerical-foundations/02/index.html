誤差ノルム L1・L2・L∞

到達目標：連続ノルムと格子幅で重み付けした離散ノルムを使い分け、局所的な大誤差も見つける。

場の誤差は場所ごとに違う。平均的にはよくても、一点だけ大きく外れている場合がある。そこで誤差の分布を、一つの大きさへまとめる約束が必要になる。これがノルムである。

L1は広がりを含む絶対量、L2は二乗を通した量、L∞は最も大きい誤差を見る。同じ誤差でも、どの問いを優先するかで評価は変わる。

連続的な定義

領域Ω上の誤差e(x)を考える。L∞では厳密には本質的上限を使う。滑らかな例では最大値と考えてよい。ノルムの単位も異なるため、数値の大小だけで優劣を決めない。

配列には格子の重みを付ける

一様なセル平均なら重みはセル幅hである。節点値の台形求積では、左右の端点だけ重みがh/2になる。非一様格子では各セル体積や求積重みを使う。比較する参照値も、点値かセル平均かを揃える。

RMSとの違い

一様なNセルで長さL=Nhなら、二乗平均平方根RMSと離散L2は√Lの係数だけ異なる。長さ1では偶然一致するが、一般の領域で同じ定義だと思ってはいけない。

小さな計算例

長さ1をN個のセルに分け、一つのセルだけ誤差を1、他を0にする。これは幅がh、高さが1の誤差を表す。

Nを増やすとL1=h、L2=√hは小さくなるが、最大誤差は1のままである。「L2が収束した」だけでは最大誤差まで消えたとは言えない。

from math import sqrt
N = 64
h = 1.0/N
e = [0.0]*N
e[N//2] = 1.0
print(h*sum(abs(x) for x in e))
print(sqrt(h*sum(x*x for x in e)))
print(max(abs(x) for x in e))

N=64ではL1=1/64、L2=1/8、L∞=1。格子数によって配列の長さが変わる比較では、重みのない単純和をPDEのL1/L2と取り違えない。

確認問題と解答

問1　重みを付けない配列の二乗和は、格子を細かくしても同じ連続量を近似するか。

解答を開く

一般にはしない。一様格子ではhを掛けてから平方根を取る必要がある。

問2　L∞も併記する利点は何か。

解答を開く

平均では見逃す局所的な大誤差を検出できる。ただし弱い解や不連続点を含む問題では期待する収束を別に考える。

つまずきやすい点

  • 節点とセル平均を比較しない。
  • 相対ノルムの分母がゼロに近くないか確かめる。

この章の要点

  • 重みと参照表現を揃える。
  • 複数のノルムで誤差の形を見る。
