小さな問題で検証する共通手順

到達目標：解析解・製造解、誤差ノルム、収束、残差、保存量・エネルギー、境界誤差を一枚の手順にまとめる。

最後に、どの分野へ進んでも使える小さな検証手順をまとめる。計算が止まらず図が滑らかに見えることと、意図した方程式を正しく解いたことは同じではない。

最初に問題を小さくし、入力・参照・判定基準を実行前に決める。失敗した実験も残し、基準を後から緩めて過去の成功へ書き換えない。

検証の比較対象を決める

解析解があれば同じ変数配置・時刻で比較する。製造解は望む解を先に置き、対応する右辺と境界値を作る方法である。参照が数値解なら、その参照の誤差と適用範囲も確認する。

複数の問いを並べる

誤差ノルムと次数、代数残差、保存量やエネルギー収支、境界・正値性・位相を別々に記録する。一つの指標だけで全てを合格にしない。理論上の安定性と、少数の固定入力での実測も区別する。

再現できる記録へする

コード・入力・環境・出力・判定基準を同じ版へ結ぶ。図は保存した数値表から作り、説明用の模式図と測定結果を区別する。ZIPだけを独立展開し、テストと例題を再実行して確認する。これは実装の検証であり、実在現象のモデル妥当性の証明とは別である。

小さな計算例

この教材のコードは標準Pythonだけで計算できる。図の再生成だけは別の描画依存を使う。初回の風上法の粗い系列で判定が一つ失敗した記録を保ち、基準は変えずに一段細かい系列へ改訂した。

不安定な対照や低次境界の例では、期待通り問題点を検出できたことを判定する。passedという一語を、全ての方法が実用上正確という意味で読まない。

python -m unittest -v test_lab.py
python lab.py --input inputs.json --output my-results
python verify_release.py
# my-results/result.json の個々の判定を読む

確認問題と解答

問1　図が似ているだけで検証完了といえるか。

解答を開く

言えない。比較条件、誤差、収束、収支、参照の精度と再現記録が必要である。

問2　製造解で合えば、物理モデルも実験に正しいと証明したか。

解答を開く

していない。意図した方程式を正しく離散化・実装できたかという検証と、モデルの妥当性は別である。

つまずきやすい点

  • 説明用の数値を実測結果に混ぜない。
  • 失敗を消したり、公差を緩めて過去の成功へ付け替えたりしない。

この章の要点

  • 実行前に問題・参照・基準を固定する。
  • 小さな例で複数の指標と再現性を確かめる。
