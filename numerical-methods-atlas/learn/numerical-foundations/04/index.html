整合性・打切り誤差・収束次数

到達目標：局所誤差と大域誤差を区別し、Taylor展開と格子・時間刻みの細分化で精度を調べる。

計算結果が基準解へ近づくことを収束という。整合性は、滑らかな厳密解を差分式へ入れたとき、その式の欠陥が刻みとともに消えるという局所的な性質である。両者は同じではない。

「2次精度」という言葉は、誤差が主にCh²で表される範囲を想定している。粗い格子、丸め、境界、反復の打切り、複数の誤差の相殺があると、観測した傾きは理論の次数から外れる。

局所誤差の約束を明示する

時間積分では、1刻みの解の欠陥そのものを局所誤差と呼ぶ場合と、それをΔtで割った量を局所打切り誤差と呼ぶ場合がある。前進Eulerでは前者がO(Δt²)、後者がO(Δt)であり、安定な有限時間の大域誤差は通常O(Δt)になる。

三つの刻みで傾きを測る

同じ物理的な時刻、同じノルム、同じ参照解を使って刻みを半分にする。次のpは観測次数で、理論次数の証明ではない。誤差が丸めの床やゼロに近い場合には、この式を無理に使わない。

参照解の誤差も疑う

厳密解がなければ、より細かい計算や別解法との比較は役立つ。ただし、その参照も近似である。時間と空間の誤差を分け、参照の細分化を確認する。Richardson型の見積りには、滑らかな漸近誤差の仮定が必要になる。

小さな計算例

周期移流を同じ時刻T=0.6まで解き、格子幅と時間刻みを同時に半分にする。風上法とLax-Wendroff法は、同じ初期波形とCourant数0.6を使う。

初回のN=40,80,160では、風上法の最初の観測次数は約0.75で、設定した0.85以上に届かなかった。公差を下げず、N=80,160,320へ細分化した。初回の入力・失敗結果もZIP内の履歴に残してある。

from math import log2
errors = [0.020, 0.005, 0.00125]
for a, b in zip(errors, errors[1:]):
    print(log2(a/b))  # この説明用配列では2
# 実測値は advection.csv を使う

実測の風上法は1次、Lax-Wendroff法は2次へ近づく。説明用の数列と実際に計算した誤差を区別し、本文中の数列を測定結果とは呼ばない。

確認問題と解答

問1　誤差が半分になると観測次数はいくつか。

解答を開く

log₂2=1。4分の1なら2。ただし同じ問題・時刻・ノルムで比較する。

問2　誤差が非常に小さい一点だけで高次法だと結論してよいか。

解答を開く

よくない。誤差相殺や丸めもあり得る。複数刻みで傾きと誤差の大きさを別々に確認する。

つまずきやすい点

  • 整合性だけで収束とは言わない。
  • 有限個の格子の傾きを一般保証にしない。

この章の要点

  • 定義・時刻・参照を固定する。
  • 観測次数が理論へ近づく範囲を探す。
