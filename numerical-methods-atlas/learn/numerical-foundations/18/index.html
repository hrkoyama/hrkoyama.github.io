シンプレクティック積分と長時間の振る舞い

到達目標：調和振動子からHamilton系の位相空間を導入し、幾何構造を保つ時間積分とエネルギーの厳密保存を区別する。

振動や軌道を長く計算するとき、1刻みの精度だけでなく、時間発展が保つ幾何構造にも目を向ける。Hamilton系の正準構造を保つのがシンプレクティック積分である。

シンプレクティック性は、元のエネルギーを毎刻み厳密に保存することとは違う。長時間の良い挙動を支える性質だが、どんな刻み・系でも正確な軌道になるという意味ではない。

位相空間と正準構造

位置qと運動量pを組にした位相空間で考える。一般の多自由度では正準2形式を保つ条件を使い、体積だけが保存されても十分ではない。1自由度の線形写像では、行列式1がシンプレクティック条件に対応する。

分割から得る二つの方法

前章の振動子のkick→driftはシンプレクティックEuler法で1次、kick半刻み→drift→kick半刻みはStörmer-Verlet法で2次になる。Verletは時間対称でもあるが、シンプレクティックEulerは一般には時間対称ではない。

保存する二次形式と物理エネルギー

この単位振動子では、固定刻みhで次の修正二次形式が厳密算術で保存される。|h|<2なら正定値なので、物理Hの誤差を抑える説明になる。一般のHamilton系でこの単純な二次式が使えるわけではない。

小さな計算例

q(0)=1、p(0)=0、h=0.1で6000歩、終時刻600まで計算する。前進Eulerはエネルギーを増やし、後退Eulerは減らす。この二つは、Hamilton振動を長く保つ目的には大きな誤差を作る。

シンプレクティックEulerとVerletではエネルギー誤差が振動する。今回の実測最大相対誤差はそれぞれ約5.26%、0.25%で、修正二次形式は丸めの範囲で保たれる。一方、終時刻の位相誤差はどちらも約0.25 rad残る。

from lab import oscillator_step
q, p, h = 1.0, 0.0, 0.1
for _ in range(6000):
    q, p = oscillator_step(q, p, h, "verlet")
print(q, p, (q*q+p*p)/2)

良いエネルギー挙動は位相の正確さと同じではない。通常の状態依存の刻み変更を加えた場合にも、固定刻みでの幾何構造や長時間評価をそのまま使わない。ここでは一般の非線形Hamilton系や適応刻みの保証を検証していない。

確認問題と解答

問1　シンプレクティックならHが毎刻み厳密に同じか。

解答を開く

一般には違う。正準構造の保存と元のHamiltonianの厳密保存は別である。

問2　この振動子でエネルギー誤差が小さければ、位相も正しいか。

解答を開く

そうとは限らない。実測では長時間の位相誤差が残るため、軌道・位相も別に調べる。

つまずきやすい点

  • 1自由度の面積保存を、多自由度の体積保存だけの条件へ読み替えない。
  • A/L安定性とHamilton系の構造保存を同じ目的だと思わない。

この章の要点

  • 何を保存する写像かを明記する。
  • エネルギー・位相・時間対称性を分ける。
