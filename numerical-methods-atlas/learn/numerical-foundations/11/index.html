数値分散：位相速度・群速度・波形

到達目標：増幅率の偏角から位相・伝播速度の誤差を読み、振幅が保たれても波形が崩れる理由を理解する。物理分散と区別する。

振幅がほぼ保たれていても、波の山が違う速さで進めば波形は変わる。数値分散は、波数によって位相の進み方が厳密な方程式からずれる作用である。数値散逸とは別の誤差として測ろう。

位相速度は一つの波の山、群速度は狭い波数帯の包絡線の進み方を読む指標である。幅広い波数を含む任意の波形に、一つの群速度を当てはめるわけではない。

複素倍率の偏角を読む

時間依存をexp(-iωt)とすれば、G=|G|exp(iφ)から数値角周波数の実部を-φ/Δtとして読める。偏角は連続につながる枝を選び、πから-πへの飛びをそのまま速度の飛びにしない。

移流なら基準速度は一定

厳密な定速移流では位相速度も群速度もaである。離散化のGを使うと、速度比をθで書ける。図では0<θ<πを使い、Nyquist端での符号・枝の曖昧さを避ける。

物理分散との区別

媒質や方程式そのものが波数に依存する伝播速度を持つ場合には、分散は物理的な性質である。ここでの基準は分散のない定速移流なので、図の速度比のずれは数値的なものになる。刻み・格子への依存を必ず示す。

小さな計算例

複素数Gの偏角を求め、位相速度の比を計算する。群速度はGの導関数から評価し、別の微小差分による偏角の導関数ともテストで照合する。

本版の移流実行は二つの正弦波の合成を運ぶ。図の群速度は離散記号からの評価であり、局在波束の中心を直接追跡した測定ではない。

from cmath import phase
from lab import symbol
nu, theta = 0.6, 0.4
G = symbol("lax-wendroff", theta, nu)
phase_speed_ratio = -phase(G)/(nu*theta)
print(phase_speed_ratio)

高波数では、振幅の減衰と位相のずれが同時に大きくなることがある。振幅が小さすぎる成分の位相測定も不安定になるため、|G|と併せて読む。

確認問題と解答

問1　|G|=1なら、波は必ず正確に運ばれるか。

解答を開く

位相が違えば正確ではない。振幅の保存と伝播速度の精度は別である。

問2　arg Gをそのまま差分すると、どんな問題があるか。

解答を開く

偏角の枝がπから-πへ跳ぶ場合、見かけの巨大な導関数を作る。枝の連続性を確認する。

つまずきやすい点

  • 群速度の式を任意の広帯域波形へ一律に当てはめない。
  • 物理分散を数値誤差として消そうとしない。

この章の要点

  • 位相と振幅を別々に測る。
  • 波数ごとの速度と解像度を結び付ける。
