Residuals, conditioning, and backward error

Learning goal: Separate sensitivity of the problem from stability of the algorithm, and understand why a small residual alone does not guarantee an accurate solution.

A linear solver can report a small residual while its solution is inaccurate. The residual measures how well the equation is satisfied; solution error measures distance from a reference solution.

A condition number describes how sensitive the solution is to small input changes. Separate this sensitivity of the problem from the algorithmic question of whether a solver introduces unnecessary error.

Relating error to residual

For a nonsingular A, solve Ax=b and denote the approximation by x̂. With residual r=b-Ax̂, we have A(x-x̂)=r. If the inverse has a large effect, even a small residual can correspond to a large solution error.

Condition number and backward error

Using the same induced matrix norm, define κ(A)=||A|| ||A⁻¹||. Backward error asks how little the input must change to make the computed answer an exact solution. Even a backward-stable method cannot guarantee a uniformly small forward error for an ill-conditioned problem.

A further layer for PDEs

Even an accurate solution of a linear system solves only an approximation to the continuous PDE. Examine algebraic residuals and discretization error separately, rather than reducing the iterative tolerance far beyond what is useful.

A small worked example

Nearly identical rows make a matrix sensitive to small input changes. Take A=[[1,1],[1,1+ε]], with ε=10⁻⁴, and choose the exact solution (1,1).

Adding δ=10⁻⁶ to the second right-hand-side entry gives the solution (1-δ/ε,1+δ/ε). Its relative residual for the original problem is about 5×10⁻⁷, but its relative solution error is about 10⁻².

eps, delta = 1.0e-4, 1.0e-6
xhat = [1-delta/eps, 1+delta/eps]
b = [2.0, 2.0+eps]
r = [2.0-xhat[0]-xhat[1],
     b[1]-xhat[0]-(1+eps)*xhat[1]]
print(xhat, r)

The infinity-norm condition number is about 4.0×10⁴. The code also checks a high-precision analytic expression using Decimal. This is an illustration of input sensitivity, not an evaluation of every linear solver.

Review questions and answers

Question 1: Does making the residual ten times smaller always reduce total PDE error by a factor of ten?

Show answer

No. Amplification associated with conditioning, and spatial and temporal discretization errors, remain.

Question 2: Does a large condition number prove that the implementation is wrong?

Show answer

The problem itself may be sensitive. Examine this separately from the backward error of the algorithm.

Common pitfalls

  • Do not mix condition numbers based on different matrix norms.
  • Do not apply nonsingular-matrix formulas directly to a singular pure-Neumann matrix.

Key points

  • A residual measures how well the equation is satisfied.
  • Solution error also depends on sensitivity of the problem.
