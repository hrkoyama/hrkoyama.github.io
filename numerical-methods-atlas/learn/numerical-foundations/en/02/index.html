Error norms: L1, L2, and L∞

Learning goal: Use continuous norms and grid-weighted discrete norms appropriately, and detect large localized errors.

The error in a field varies from place to place. An approximation can be good on average and still have a large error at one point. A norm specifies how to summarize the error distribution as one magnitude.

L1 measures integrated absolute error, L2 uses squared error, and L∞ measures the largest error. The same error distribution can receive different assessments depending on which question matters.

Continuous definitions

Consider an error e(x) on a domain Ω. Strictly, L∞ uses the essential supremum; for the smooth examples here, it can be read as the maximum. The norms can also have different units, so their numerical magnitudes alone do not rank their usefulness.

Weight arrays by the grid

For uniform cell averages, the weight is the cell width h. For trapezoidal quadrature of nodal values, the two endpoint weights are h/2. On nonuniform grids, use cell volumes or quadrature weights. Match the reference representation too: point values and cell averages differ.

The distinction from RMS

For N uniform cells over a length L=Nh, the discrete L2 norm differs from the root mean square, RMS, by a factor √L. They happen to coincide when L=1, but are not the same definition on a general domain.

A small worked example

Divide a unit interval into N cells and set the error to 1 in one cell and 0 elsewhere. This represents an error of height 1 and width h.

As N increases, L1=h and L2=√h decrease, but the maximum error stays at 1. Convergence in L2 alone does not show that the maximum error vanishes.

from math import sqrt
N = 64
h = 1.0/N
e = [0.0]*N
e[N//2] = 1.0
print(h*sum(abs(x) for x in e))
print(sqrt(h*sum(x*x for x in e)))
print(max(abs(x) for x in e))

For N=64, L1=1/64, L2=1/8, and L∞=1. When the array length changes with grid resolution, do not confuse an unweighted array sum with a PDE L1 or L2 norm.

Review questions and answers

Question 1: Does an unweighted sum of squared array entries approximate the same continuous quantity as the grid is refined?

Show answer

Generally no. On a uniform grid, multiply the sum by h before taking the square root.

Question 2: Why also report L∞?

Show answer

It detects large local errors that an average can miss. For weak solutions or problems with discontinuities, assess the expected kind of convergence separately.

Common pitfalls

  • Do not compare nodal values directly with cell averages.
  • Check that the denominator in a relative norm is not near zero.

Key points

  • Match the weights and reference representation.
  • Use several norms to examine the shape of the error.
