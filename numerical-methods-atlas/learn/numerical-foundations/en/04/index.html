Consistency, truncation error, and convergence order

Learning goal: Distinguish local and global error, and investigate accuracy using Taylor expansions and refinement in space and time.

Convergence means that a computed solution approaches a reference solution. Consistency is a local property: the defect obtained by substituting a smooth exact solution into the discrete equation vanishes as the steps shrink. These are different concepts.

Second-order accuracy describes a regime where the leading error behaves like Ch². Coarse grids, roundoff, boundaries, incomplete iteration, or cancellation between error terms can make an observed slope differ from the theoretical order.

State the local-error convention

In time integration, local error may mean the one-step solution defect itself, while local truncation error may mean that defect divided by Δt. For forward Euler these are O(Δt²) and O(Δt), respectively. For a stable calculation over finite time, the global error is usually O(Δt).

Measure slopes with three spacings

Halve the spacing while keeping the physical comparison time, norm, and reference solution the same. The p below is an observed order, not a proof of theoretical order. Do not force this formula onto errors close to zero or the roundoff floor.

Question the reference error too

Without an exact solution, comparison with a finer computation or a different method is useful. That reference is still approximate. Separate temporal and spatial errors, and check refinement of the reference itself. Richardson-type estimates assume a smooth asymptotic error expansion.

A small worked example

Solve periodic advection to the same time T=0.6, halving the grid spacing and time step together. The upwind and Lax-Wendroff methods use the same initial waveform and Courant number 0.6.

For the first sequence N=40,80,160, the first observed upwind order was about 0.75, below the prescribed lower bound 0.85. We refined to N=80,160,320 without lowering that bound. The initial input and failed results remain in the ZIP history.

from math import log2
errors = [0.020, 0.005, 0.00125]
for a, b in zip(errors, errors[1:]):
    print(log2(a/b))  # 2 for this illustrative array
# Use advection.csv for measured errors

The measured upwind order approaches 1 and the Lax-Wendroff order approaches 2. Distinguish the illustrative number sequence from errors computed by the actual experiment; the sequence in the prose is not a measurement.

Review questions and answers

Question 1: What observed order results if halving the spacing halves the error?

Show answer

log₂2=1. A reduction to one quarter gives 2. Compare the same problem, time, and norm.

Question 2: Can a single extremely small error establish that a method has high order?

Show answer

No. Error cancellation or roundoff may be involved. With several steps, examine the slope separately from the error magnitude.

Common pitfalls

  • Consistency alone does not establish convergence.
  • A slope over finitely many grids is not a general guarantee.

Key points

  • Fix the definitions, comparison time, and reference.
  • Find the range where observed order approaches theory.
