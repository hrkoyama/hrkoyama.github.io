von Neumann Fourier stability analysis

Learning goal: Examine amplification by wavenumber, primarily for constant coefficients on a uniform grid with periodic or infinite domains.

Insert a periodic sinusoidal wave and examine how the difference scheme changes its amplitude and phase. A linear, constant-coefficient scheme on a uniform grid can be decomposed into Fourier modes. This is von Neumann analysis.

Neumann is a person's name here. This analysis is not the procedure for imposing the normal-derivative Neumann boundary condition introduced later. Boundary treatments on finite domains require checks beyond the interior Fourier analysis.

Substitute a single mode

Insert a complex grid mode exp(i jθ) into the difference equation. Linearity and constant coefficients preserve its shape at the next time, multiplied by a complex number G. Real waves can be represented using the real and imaginary parts. Here i is the imaginary unit satisfying i²=-1, and exp(i jθ)=cos(jθ)+i sin(jθ). Complex notation handles sine and cosine together.

Upwind and Lax-Wendroff schemes

Consider advection with speed a>0 and Courant number ν=aΔt/h. For a continuous wavenumber k, θ=kh. Examine the full range representable by the grid, not just low wavenumbers.

The roles of magnitude and argument

For a scalar periodic problem, |G|≤1 for every mode ensures that discrete L2 does not grow. This is a useful sufficient condition. Lax-type uniform stability can also allow bounds such as 1+CΔt; a value of |G| slightly greater than 1 alone is not a universal instability test. The argument describes phase error, examined in Chapter 11.

A small worked example

The code checks both the analytic G and the result of advancing a complex Fourier array by one step of the actual difference update. These provide separate paths for checking the derived formula and implementation signs.

For FTCS with Courant number 0.6, θ=π/2 gives |G|=√(1+0.6²)>1. This fixed factor is raised to an increasing number of steps, destroying uniform stability at fixed physical time.

from cmath import exp
from math import pi
nu, theta = 0.6, pi/2
g_up = 1-nu+nu*exp(-1j*theta)
print(abs(g_up), g_up.real, g_up.imag)

Review questions and answers

Question 1: Is checking only long waves enough to establish stability?

Show answer

No. Short grid-wavelength modes may be unstable.

Question 2: With finite-domain boundaries, is the interior |G| generally sufficient?

Show answer

No. Also examine a matrix or energy estimate including the boundaries, and actual boundary-condition examples.

Common pitfalls

  • Do not extend this analysis unconditionally to variable coefficients, nonlinear equations, or nonuniform grids.
  • For multiple components or nonnormal systems, consider more than eigenvalues.

Key points

  • Substitute the mode into the actual difference equation.
  • Read amplitude and phase separately.
