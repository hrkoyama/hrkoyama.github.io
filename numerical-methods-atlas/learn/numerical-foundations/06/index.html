絶対安定性と安定領域

到達目標：試験方程式 y'=λy と増幅関数 R(λΔt) を使い、時間刻みと増幅・減衰を結び付ける。

まず一つの減衰成分だけを取り出す。試験方程式y′=λyでは、厳密解はexp(λt)であり、Re λ<0なら減衰する。時間積分法がこの成分を一歩ごとにどう扱うかを、複素平面で調べよう。

数値解の1刻みの倍率R(z)を安定性関数と呼ぶ。z=λΔtは、問題の時間スケールと選んだ刻みを一つにまとめた量である。

増幅率から安定領域へ

線形の1ステップ法を試験方程式へ適用し、|R(z)|≤1となるzの集合を絶対安定領域とする。これはこの試験方程式の反復が増えない条件であり、位相や正確さまで保証するものではない。

三つの基本公式

前進Eulerは古い時刻、後退Eulerは新しい時刻の傾きを使う。台形則は両端の平均を使う。下式は線形試験方程式での関数であり、一般の非線形問題では後退Eulerや台形則は方程式を解く必要がある。

領域に入っていても誤差はある

前進Eulerの領域は中心-1、半径1の円板である。負の実軸では-2≤z≤0となる。境界で|R|=1なら、厳密解が減衰していても数値解が減衰しない場合がある。精度は刻みを変えて別に調べる。

小さな計算例

λ=-1、T=1でステップ数を10,20,40,80と変える。各法の値R(-Δt)^Nをexp(-1)と比較する。

前進・後退Eulerでは誤差はおよそ1次、台形則ではおよそ2次となる。安定領域の広さと近似次数は別の性質である。

from math import exp
N = 20
dt = 1.0/N
z = -dt
forward = (1+z)**N
backward = (1/(1-z))**N
trapezoidal = ((1+z/2)/(1-z/2))**N
print(exp(-1), forward, backward, trapezoidal)

この固定系列では三つの法の大域誤差の次数を個別に判定する。図の着色領域は複素zの安定性で、実測した誤差の大きさを表す色ではない。

確認問題と解答

問1　λ=-10、前進EulerでΔt=0.3を使うとどうなるか。

解答を開く

z=-3、R=-2で、絶対値は2となり増幅する。

問2　|R|≤1なら、粗い刻みでも厳密解に近いか。

解答を開く

近いとは限らない。安定性は不要な増幅を抑える条件で、精度の検査とは別である。

つまずきやすい点

  • 複素λを実部だけへ置き換えて領域を判定しない。
  • 一般の非正規行列へ固有値だけの議論を無条件に拡張しない。

この章の要点

  • λΔtを安定領域と照らす。
  • 精度と安定性を別々に測る。
