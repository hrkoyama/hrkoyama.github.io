閉殻Hartree–Fock方程式

F^=h^+∑j∈occ(2J^j−K^j),F^ϕi=εiϕi\hat F=\hat h+\sum_{j\in\mathrm{occ}}(2\hat J_j-\hat K_j),\qquad \hat F\phi_i=\varepsilon_i\phi_iF^=h^+j∈occ∑​(2J^j​−K^j​),F^ϕi​=εi​ϕi​
FC=SCε,C†SC=I\mathbf F\mathbf C=\mathbf S\mathbf C\boldsymbol\varepsilon,\qquad \mathbf C^\dagger\mathbf S\mathbf C=\mathbf IFC=SCε,C†SC=I

閉殻RHFの占有空間軌道の式。一般に非局所な交換を含む。実行例は球対称1s² Heの局所還元に限定し、一般の分子・多電子のFock行列構築は未実装。

[−12∇2+vext+vH+vxc]ϕi=εiϕi[-\tfrac12\nabla^2+v_{\rm ext}+v_H+v_{\rm xc}]\phi_i=\varepsilon_i\phi_i[−21​∇2+vext​+vH​+vxc​]ϕi​=εi​ϕi​
n(r)=∑ifi∣ϕi(r)∣2,∫n dr=N,vxc=δExcδnn(\mathbf r)=\sum_i f_i|\phi_i(\mathbf r)|^2,\quad \int n\,d\mathbf r=N,\quad v_{\rm xc}=\frac{\delta E_{\rm xc}}{\delta n}n(r)=i∑​fi​∣ϕi​(r)∣2,∫ndr=N,vxc​=δnδExc​​

密度汎関数の局所KS代表形。実行例は球対称He・スピン非偏極Dirac交換のみLDA。相関・GGA・hybrid・一般化KS・周期系は未実装。

ZIPを展開し、実行の案内に示す作業フォルダで使うコマンドです。配布版の複数例をまとめて実行する場合があります。

python -m pytest -q

Conditions, commands and validation scope

Assumptions

Nonrelativistic infinite-mass point nucleus, two electrons doubly occupying a single 1s spatial orbital. Second-order central differences and linear density mixing. Local HF exchange reduction is specific to this two-electron problem.

Use these commands in the working directory specified by the execution guide after extracting the ZIP. A command may execute several cases in the package.

python -m pip install -r requirements-dev.txt
python run.py --input inputs.json --reference reference-pyscf.json --output output --figures
python -m pytest -q

Validation limits

Compare spherical 1s² closed-shell helium HF and spin-unpolarized Dirac exchange-only LDA. No electron correlation, molecules or periodic systems.
