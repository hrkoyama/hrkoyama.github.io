理想MHD

ρt+∇⋅(ρv)=0\rho_t+\nabla\cdot(\rho\boldsymbol v)=0ρt​+∇⋅(ρv)=0
(ρv)t+∇⋅[ρv⊗v+(p+B2/2)I−B⊗B]=0(\rho\boldsymbol v)_t+\nabla\cdot[\rho\boldsymbol v\otimes\boldsymbol v+(p+B^2/2)I-\boldsymbol B\otimes\boldsymbol B]=0(ρv)t​+∇⋅[ρv⊗v+(p+B2/2)I−B⊗B]=0
Et+∇⋅[(E+p+B2/2)v−(v⋅B)B]=0E_t+\nabla\cdot[(E+p+B^2/2)\boldsymbol v-(\boldsymbol v\cdot\boldsymbol B)\boldsymbol B]=0Et​+∇⋅[(E+p+B2/2)v−(v⋅B)B]=0
Bt=∇×(v×B),∇⋅B=0\boldsymbol B_t=\nabla\times(\boldsymbol v\times\boldsymbol B),\quad\nabla\cdot\boldsymbol B=0Bt​=∇×(v×B),∇⋅B=0

透磁率を1とする理想MHDの代表形。Eは熱・運動・磁場を含む全エネルギー密度。解説でCT・GLMと発散の測り方、HLLDテストへ進めます。

厳密解・参照解

円偏光Alfvén波の解析解を、一定の全エネルギーを含む保存変数セル平均で評価します。 実行前契約で47pytest・全12計算を固定。3格子と最細格子の時間刻み半減を分離し、全段の正値性・有限性、保存量、Courant数、5時刻の実場を保存します。解析保存平均を独立Gauss16求積と照合し、横成分誤差・位相・観測次数を検査します。

ZIPを展開し、実行の案内に示す作業フォルダで使うコマンドです。配布版の複数例をまとめて実行する場合があります。

検証の限界

少数の固定入力に対する教育用検証です。HLLDのHLLE代替と再構成の正値性スケーリングを数え、セル状態の床・クリップ・再試行は行いません。有限格子参照は厳密解ではなく、任意問題の安定性・正値性や普遍的次数を保証しません。1次元整列波の次数であり、斜め2次元伝播の検証ではありません。

Assumptions

Use these commands in the working directory specified by the execution guide after extracting the ZIP. A command may execute several cases in the package.

python -m pip install -r requirements.txt
python -m pytest -q
python run.py --input inputs.json --output output

Validation limits

Educational fixed inputs only. Count HLLD-to-HLLE fallbacks and face reconstruction positivity scaling; no cell floor/clipping/retry. Finite-grid references are not exact solutions; no universal stability, positivity or order guarantee. The observed order is for a 1D aligned wave, not oblique 2D propagation.
