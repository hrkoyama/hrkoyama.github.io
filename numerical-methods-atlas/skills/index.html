使い方

  1. ZIPを取得し、nan-numerics/フォルダを展開します。
  2. Agent Skills形式に対応したツールの案内に従い、このフォルダを必要なプロジェクトや会話へ明示的に読み込ませます。SKILL.mdとreferences/の位置関係を保ってください。
  3. 解きたい方程式、境界条件、観測量、精度目標を伝え、使ったページ・コード版・入力・確認した検証量を回答に残すよう依頼します。

依頼の例

1次元Bratuの合成観測からλを推定するコードを開発したい。境界はu(0)=u(1)=0、λ≈3。NaNから実行例を選び、実装前に確認する条件と、パラメータ勾配・推定結果を確かめる具体的な手順を、出典とコード版付きで提案して。

対応するBratu逆問題の解説と固定配布版を参照できます。

確認した範囲

スキル本文を使い、Bratu逆問題の資料探索・実行例の選択・検証計画を、独立した読取専用の試行1件で確認しました。資料ルート案内は試行後に補足しています。変更したコードの動作、新しい科学計算、軽量・低コストLLMとの比較、費用や精度への効果は未検証です。

Use the package

  1. Download the ZIP and extract the nan-numerics/ folder.
  2. Follow your Agent Skills-capable tool's documented procedure to explicitly load the folder for the project or conversation where you need it. Keep SKILL.md and references/ in their relative locations.
  3. State the equation, boundaries, observable and accuracy target. Ask the assistant to retain source URLs, code editions, inputs and checked quantities in its response.

Example request

I want to develop code that estimates lambda from synthetic observations of the one-dimensional Bratu problem, with u(0)=u(1)=0 and lambda around 3. Choose a runnable NaN example, identify the conditions to confirm before implementation, and propose concrete checks of the parameter gradient and fitted result. Include sources and the code edition.

See the Bratu inverse-problem chapter and its fixed code edition.

What has been checked

One independent, read-only trial used the skill instructions to retrieve Bratu resources, select an example and prepare a verification plan. The resource-route guide was clarified afterward. Modified-code execution, new scientific calculations, comparisons with lightweight or lower-cost LLMs, and effects on cost or accuracy remain unverified.
