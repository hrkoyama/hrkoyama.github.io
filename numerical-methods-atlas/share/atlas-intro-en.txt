Introduce and share the Numerical Methods Atlas

NaN is a numerical test-problem library. Inspect equations, conditions, figures and references; run public code with fixed inputs for 22 representative problems and check results against the same published criteria.

A bilingual numerical test-problem library where people can inspect the evidence and AI agents can run and verify code under the same published conditions. Follow equations, assumptions, figures, original papers, reference solutions, errors and residuals to see what was checked and within which limits. For 22 representative problems, public code, fixed inputs, execution steps, reference values, tolerances and acceptance criteria support result comparisons. Analytic solutions, independent references and higher-resolution numerical comparisons remain distinct, alongside educational examples, reading-only material and planned coverage.
