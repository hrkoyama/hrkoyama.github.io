Stiff integration: solve the stage, control the time error

Implemented: backward Euler, constant-step BDF2 with backward-Euler startup, two-stage SDIRK2, first-order IMEX Euler, and adaptive SDIRK2 by step doubling. All nonlinear stages use damped Newton and report failure explicitly.

Implicit stages and stability#

Backward Euler solves y_new−y_old−h f(t_new,y_new)=0. BDF2 solves

3yn+1−4yn+yn−12h=f(tn+1,yn+1). \frac{3y_{n+1}-4y_n+y_{n-1}}{2h}=f(t_{n+1},y_{n+1}). 2h3yn+1​−4yn​+yn−1​​=f(tn+1​,yn+1​).

Alexander (1977) is the source for the L-stable, two-stage, second-order singly diagonally implicit family used here:

γ=1−1/2,A=(γ01−γγ),b=(1−γ,γ),c=(γ,1). \gamma=1-1/\sqrt2,\qquad A=\begin{pmatrix}\gamma&0\\1-\gamma&\gamma\end{pmatrix}, \quad b=(1-\gamma,\gamma),\quad c=(\gamma,1). γ=1−1/2​,A=(γ1−γ​0γ​),b=(1−γ,γ),c=(γ,1).

Each diagonal stage is a separate nonlinear solve. An implicit method can permit steps beyond an explicit stability limit, while accuracy still limits useful step size. A converged Newton residual measures the stage equation, not the temporal discretization error.

Adaptive and split steps#

The adaptive implementation compares one full SDIRK2 step with two half steps. The local error estimate is (y_half−y_full)/3, scaled by atol+rtol max(|y_old|,|y_half|). It accepts the two-half-step value, without Richardson extrapolation, and adjusts h with exponent −1/3. Rejected trials and accepted steps are counted; reaching a trial limit raises an error.

IMEX Euler evaluates one part explicitly and the other implicitly. This minimal first-order split is not the higher-order IMEX RK constructions of Ascher–Ruuth–Spiteri (1997). The explicit part retains its own stability restriction. Variable-step BDF, embedded DIRK pairs and operator splitting remain extensions.

The stiff test y′=−1000(y−cos t)−sin t has exact solution cos t when y(0)=1. The manifest records maximum errors at actual integration nodes and adaptive step counts. Separate tests verify order on a nonlinear, nonautonomous ODE and strong damping of a stiff decay mode.

The coarse stiff-forced refinement is not in a uniform second-order regime. BDF2 startup and stiff order reduction affect the maximum-over-nodes error; the nonlinear nonstiff order test checks the formal temporal order separately.

For definitions and comparisons of A-stability, L-stability and L1/L2/L∞ error norms, see the shared accuracy and stability guide.

An operator-splitting reading now compares first-order Lie–Trotter and second-order Strang with a small exact-flow illustration. It does not add a general splitting implementation to this chapter’s existing solver package. A lightweight fixed-input example now runs both on the same reaction–diffusion problem.
