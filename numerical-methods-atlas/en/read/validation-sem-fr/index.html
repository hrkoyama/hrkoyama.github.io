Spectral elements and FR: small comparisons with existing FEM/DG

Explore this chapter

  • Methods

  • Exact / reference solutions

Compare2D SEM Poisson and1D periodic FR advection with the existing P1 FEM/modal DG under matched equations, boundaries and analytic fields. Separate h/p refinement, continuous error, residuals, conservation and time error from any external Nek/PyFR execution.

These additional validation supplements are managed separately from the common 22-example registry. Receipts cover independent ZIP extraction, tests and every fixed input within each group. Changes of settings, methods or step sizes do not add independent physical problems.

Routine supplement CI runs the supplement groups listed in the public registry with NumPy,SciPy and pytest. It checks versions,inputs and execution records for stored independent references and distinguishes their reuse from new reference computations. The existing common22-case suite,including quantum convergence,remains manual on explicit need; released artifacts,criteria and history are preserved.

Run inside atlas-sem-fr-2026-11-23 from the ZIP. This command executes all 2 fixed cases in the supplement. The bundled results/ contains stored outputs. Rerun into a new output/ directory, and choose another fresh directory for subsequent runs.

python -m pip install -r requirements.txt
python -m pytest -q
python run.py --input inputs.json --output output

Matplotlib is optional for redrawing saved figures; ordinary scientific execution does not require it.
