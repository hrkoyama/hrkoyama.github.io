Interactive experiment guide

The basis notebook adds computed reference-element algebra: Legendre and Lagrange shapes, exact versus GLL-quadrature matrices, smooth/jump approximation, and triangular P2 functions. Its saved arrays and source hashes come from scripts/build_basis.py; it does not introduce a new PDE evolution solver.

The web edition now includes a stability laboratory and a convergence notebook. The laboratory computes in the browser; the convergence notebook displays measurements from the original gallery manifest. These are distinct sources of evidence.

Periodic advection in the browser#

The model is

ut+aux=0,x∈[0,1],u(x+1,t)=u(x,t). u_t+a u_x=0,\qquad x\in[0,1],\qquad u(x+1,t)=u(x,t). ut​+aux​=0,x∈[0,1],u(x+1,t)=u(x,t).

Use 64 cell-centered sample points, h=1/64, velocity a=+1 or a=-1, and Δt=|C|h. The signed Courant number is C=aΔt/h. The controls expose 0.05≤|C|≤1.5 and 0–100 time steps. The exact comparison samples the continuous translated profile u(x-at,0) at the same grid points.

Initial data can be a sine wave, a square pulse equal to one on [0.25,0.65) and zero elsewhere, or a sine wave with small high-frequency perturbations:

u(x,0)=sin⁡(2πx)+10−3[sin⁡(2π(N/2)x)+cos⁡(2π(N/4)x)]. u(x,0)=\sin(2\pi x)+10^{-3} \left[\sin(2\pi(N/2)x)+\cos(2\pi(N/4)x)\right]. u(x,0)=sin(2πx)+10−3[sin(2π(N/2)x)+cos(2π(N/4)x)].

The ripple seeds both Nyquist and shorter resolved grid-scale modes. It makes unstable growth visible without relying on machine roundoff. The square pulse illustrates smearing and dispersive oscillations; it is not a smooth convergence test.

Four discrete updates#

numart.advection.difference_step and the browser implement FTCS, upwind, classical Lax–Friedrichs, and Lax–Wendroff. Upwind switches stencil with the velocity sign. The stability chapter develops their context. For FTCS,

ujn+1=ujn−C2(uj+1n−uj−1n),G(θ)=1−iCsin⁡θ. u_j^{n+1}=u_j^n-\frac C2(u_{j+1}^n-u_{j-1}^n),\qquad G(\theta)=1-iC\sin\theta. ujn+1​=ujn​−2C​(uj+1n​−uj−1n​),G(θ)=1−iCsinθ.

Its squared amplification is 1+C²sin²θ. Consequently, nonzero C produces growing modes even when the necessary domain-of-dependence bound |C|≤1 is met. Upwind, LF, and LW satisfy the Fourier stability criterion for this periodic constant-coefficient problem when |C|≤1.

The solution plot updates alongside |G(θ)|. The reported maximum samples all distinct real-data Fourier wavenumbers of the 64-point grid. The dashed threshold marks |G|=1. When the solution grows, its vertical scale expands rather than clipping the computed values. Pointwise L1 error, maximum amplitude, and arithmetic mean drift are reported separately.

These properties concern this linear periodic model. They do not transfer automatically to nonlinear systems, other boundaries, or a different time integrator. With unstable growth, cancellation and floating-point rounding can also corrupt the measured mean.

Reproducibility and export#

The browser kernels are compared with 24 reference cases generated from the Python implementation: four methods, six signed Courant numbers, and twelve updates per case. Tests compare complete sample arrays and complex Fourier amplification factors. Separate tests check exact one-cell translation at unit CFL, direction reversal, periodic wrapping, and observed-order arithmetic. The fixture records the SHA-256 of numart/advection.py; a source mismatch fails the browser numerical tests until the reference export is refreshed.

The experiment download contains settings, grid coordinates, initial, computed, and exact samples, diagnostics, and the Python reference hash. It records a calculation performed in JavaScript, rather than claiming that Python runs in the browser.

To apply the same stencil from Python:

import numpy as np
from numart.advection import difference_step

n, courant, steps = 64, 0.8, 40
x = (np.arange(n) + 0.5) / n
q = np.sin(2 * np.pi * x)
for _ in range(steps):
    q = difference_step(q, courant, "lax-wendroff")
exact = np.sin(2 * np.pi * (x - courant * steps / n))
print("pointwise L1 error:", np.mean(abs(q - exact)))

Reading a refinement study#

The notebook uses the first-edition docs/figures/validation.json measurements. The original manifest, including source hashes and runtime versions, is available for download. These data predate the browser laboratory and are not new wall-clock measurements.

For successive meshes, the displayed observed order is

pobs=log⁡(Ecoarse/Efine)log⁡(Nfine/Ncoarse). p_{\mathrm{obs}}= \frac{\log(E_{\mathrm{coarse}}/E_{\mathrm{fine}})} {\log(N_{\mathrm{fine}}/N_{\mathrm{coarse}})}. pobs​=log(Nfine​/Ncoarse​)log(Ecoarse​/Efine​)​.

DG advection: periodic scalar transport, final time 0.2, CFL 0.2, N=8,16,32,64, modal Legendre P0/P1/P2, and SSPRK3. The error is RMS sampled at the implementation's quadrature points. It is not a separately integrated L2 norm. Pp stores N(p+1) scalar unknowns. Toggle the horizontal axis between elements and unknowns; the data remain unchanged. Spatial orders 1, 2, and 3 and SSPRK3's time order three explain the expected smooth behavior.

Euler entropy wave: final time 1, CFL 0.3, N=40,80,160, primitive minmod MUSCL or componentwise FD WENO5-JS with SSPRK3. The error is pointwise density L1. WENO's fifth-order spatial reconstruction does not remove the third-order time error, so slopes from this finite sequence do not guarantee asymptotic fifth-order fully discrete convergence. Euler stores three scalar state components per point or cell; equal counts do not imply equal computational cost or identical approximation spaces.

A decreasing error, an observed slope, a positivity test, a small divergence, and a performance comparison answer different questions. The notebook keeps those distinctions explicit. See the benchmark definitions and the implementation roadmap for the remaining checks.

Temporal trajectories and mesh connectivity#

The time integration notebook selects Python-computed y′ = i y trajectories for twelve temporal methods, with fixed final time 20. It exposes step size, leapfrog startup perturbation, two characteristic roots, sampled error, and amplitude. These are precomputed ODE results, unlike the browser-computed spatial stability laboratory. Read the time integration definitions.

The mesh explorer displays three explicit vertex/cell datasets. Selection highlights face-sharing neighbors; the cell dropdown and keyboard-accessible polygons provide equivalent controls. Geometry is fixed, and no flow is integrated. Read mesh definitions, ALE, and SPH.

Both notebooks expose foundations.json, generated by scripts/sync_web_content.py, with source SHA-256 hashes for the temporal and geometry modules. Their Python tests check refinement orders, leapfrog modes, midpoint amplitude, kernel normalization, mesh topology, and moving-volume uniform-state preservation.

Hamiltonian maps#

The Hamiltonian notebook loads 30 Python-computed cases on demand. It compares energy errors at a shared fixed step, then lets readers inspect one map’s phase-space orbit or square-boundary image. Analytic local Jacobian diagnostics distinguish symplectic structure from energy preservation. Read the definitions. Regenerate the dataset and figure with python scripts/build_hamiltonian.py.

Nonsteady movie and KEEP exhibits#

The motion gallery presents actual saved solver states and explicit physical timestamps, with fixed color scales and MP4 export. KEEP is evaluated on a smooth exact-reference vortex, with separate spatial/time-refinement and entropy diagnostics. No shock-capturing claim follows from that smooth computation.

Slope limiters and advanced reconstruction#

The limiter notebook loads 45 Python-computed curves on demand, together with six smooth-refinement studies and three constructed Euler reconstruction failures. Select minmod, Superbee, MC, van Leer, or clipped van Albada, inspect scalar periodic TV and mass, and compare Sod with the same HLLC flux. Scalar errors use exact cell averages; Sod retains its pointwise reference convention. First-order and unlimited baselines apply only to scalar advection.

The advanced controls select TVB M=0,10,50 and demonstrate conservative positive-state scaling. Read slope definitions and the advanced assumptions. python scripts/build_limiters.py generates docs/figures/limiters.json with source hashes; the standard sync copies it to the web edition. Neither the scalar TVB example nor the positive reconstruction helper confers a fully discrete Euler positivity guarantee.

Runge–Kutta family notebook#

The family notebook compares nine fixed-step explicit RK tableaus. Three RK2 methods share a linear stability polynomial but differ on the nonlinear y′=−y² test. Select a one-step size, inspect actual RHS-stage predictors, and compare sampled stability contours and final-time refinement. Formal order, stage count, nonlinear SSP coefficient, and RHS work are displayed separately. Read the RK chapter for all definitions and conditional SSP assumptions. python scripts/build_runge_kutta.py creates the plotted data and source manifest. The existing oscillator notebook now offers twelve temporal methods; its implicit options remain scalar linear models.

CIP value and gradient transport#

The CIP notebook compares original cubic-Hermite CIP with linear point interpolation on uniform periodic scalar advection. It displays the independently transported gradient, derivative-initialization choices, smooth refinement, overshoot on a square pulse, and an analytic conservation counterexample. Read the definitions; point samples and finite-volume averages are not interchangeable. Rebuild with python scripts/build_cip.py before syncing.

For definitions and comparisons of A-stability, L-stability and L1/L2/L∞ error norms, see the shared accuracy and stability guide.
