These additional validation supplements are managed separately from the common 22-example registry. Receipts cover independent ZIP extraction, tests and every fixed input within each group. Changes of settings, methods or step sizes do not add independent physical problems.

Routine supplement CI runs the supplement groups listed in the public registry with NumPy,SciPy and pytest. It checks versions,inputs and execution records for stored independent references and distinguishes their reuse from new reference computations. The existing common22-case suite,including quantum convergence,remains manual on explicit need; released artifacts,criteria and history are preserved.
