## 厳密解・参照解

- [Orszag–Tang渦（CT・GLM・発散誤差摂動を統合）：参照・比較条件](<https://hrkoyama.github.io/numerical-methods-atlas/problems/orszag-tang/?lang=ja#references-ja>)

  保存則・各離散配置に対応する磁場発散と、別実行のAthena++数値参照を確認します。この非線形MHD問題の厳密解を提供するものではありません。
- [Brio–Wu衝撃波管：参照・比較条件](<https://hrkoyama.github.io/numerical-methods-atlas/problems/brio-wu/?lang=ja#references-ja>)

  同一コードの細格子数値参照と独立Athena++参照を区別します。共平面γ=2のBrio–Wuについて、厳密解や普遍的一意性を主張しません。
- [円偏波Alfvén波：参照・比較条件](<https://hrkoyama.github.io/numerical-methods-atlas/problems/circular-alfven/?lang=ja#references-ja>)

  円偏光Alfvén波の解析解を、一定の全エネルギーを含む保存変数セル平均で評価します。
- [磁場ループの移流：参照・比較条件](<https://hrkoyama.github.io/numerical-methods-atlas/problems/magnetic-loop/?lang=ja#references-ja>)

  弱磁場ループが1周期で戻る初期場との誤差、磁気エネルギー、配置固有の磁場発散を確認します。任意強度のMHDループの厳密解を主張しません。
- [Brio–Wu：HLLDと保存的に粗視化した数値参照：参照・検証](<https://hrkoyama.github.io/numerical-methods-atlas/code-and-data/examples/brio-wu/?lang=ja#brio-wu-ja-validation>)

  512セルの保存変数を64/128セルへ整数ブロック平均し、その後にprimitive変数へ変換する。CSVは128セルごとに計算値とそのセル平均に対応する参照値を配置。正値性、縦磁場10^-12、境界流束収支10^-10、経験的な誤差減少を別々に判定し、fallback回数を隠さない。

## コード・検証

- [Orszag–Tang：CT・GLMと独立Athena++比較](<https://hrkoyama.github.io/numerical-methods-atlas/validation/ct-glm-independent/?lang=ja>)
  availability: run

  同じ周期Orszag–Tang初期値で、CTとGLMの密度・磁場、保存量、div Bを測り、別に実行したAthena++と比較します。
- [Orszag–Tang：条件を揃えたCT・GLMと独立参照の収束](<https://hrkoyama.github.io/numerical-methods-atlas/validation/ct-glm-ot-convergence/?lang=ja>)
  availability: run

  同じOT初期セル平均と同じdt列でCT/GLMを計算し、別に実行したAthena++の格子・時間感度を分離した参照と比較します。
- [CT・GLM：移動する磁気静力学平衡の格子・時間収束](<https://hrkoyama.github.io/numerical-methods-atlas/validation/ct-glm-smooth-convergence/?lang=ja>)
  availability: run

  非零の磁気力と圧力勾配が釣り合う構成厳密解を使い、同じ初期セル状態・流束の速度上界・刻み列でCT/GLMを比較します。
- [Brio–Wu：HLLDと保存的に粗視化した数値参照](<https://hrkoyama.github.io/numerical-methods-atlas/code-and-data/examples/brio-wu/?lang=ja>)
  availability: run

  γ=2、Bx=0.75の1次元理想MHD衝撃波管をt=0.1まで計算。HLLD＋MC＋SSPRK2の64/128セルを512セルの数値参照と比較し、密度・圧力・縦磁場・保存収支・切替回数を記録する。
- [Brio–Wu：別実装HLLDとの照合](<https://hrkoyama.github.io/numerical-methods-atlas/validation/brio-independent/?lang=ja>)
  availability: run

  公開HLLD-MC有限体積コードを、固定コミットから別に構築したAthena++のBrio–Wu参照と比較します。
