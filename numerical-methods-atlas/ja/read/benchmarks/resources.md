## 厳密解・参照解

- [Sod衝撃波管：参照・比較条件](<https://hrkoyama.github.io/numerical-methods-atlas/problems/sod/?lang=ja#references-ja>)

  理想気体γ=1.4の標準Sod初期値に対する半解析的Riemann解が基準です。同じ問題でも点値・保存変数のセル平均・格子と誤差ノルムは同一とは限りません。
- [Euler／Sod問題](<https://hrkoyama.github.io/numerical-methods-atlas/solutions/?lang=ja#solution-euler-sod-ja>)
  relation: related-model
  reference_kind: semi-analytic

  半解析解 比熱比gamma>1の理想気体、平面1次元波。真空の保存変数はゼロ、速度は未定義です。 γ=1.4、左右(ρ,u,p)=(1,0,1)/(0.125,0,0.1)、x0=0.5、[0,1]、t=0.2が一致します。点値・保存セル平均・誤差ノルムは別に確認します。 物理的な入力は一致しますが、参照カードの点値標本と保存計算の有限体積セル平均・離散格子は別表現です。
- [Lax衝撃波管：参照・比較条件](<https://hrkoyama.github.io/numerical-methods-atlas/problems/lax/?lang=ja#references-ja>)

  左右状態(0.445,0.698,3.528)と(0.5,0,0.571)、γ=1.4の半解析的Riemann解が基準です。
- [Euler／Lax問題](<https://hrkoyama.github.io/numerical-methods-atlas/solutions/?lang=ja#solution-euler-lax-ja>)
  relation: related-model
  reference_kind: semi-analytic

  半解析解 比熱比gamma>1の理想気体、平面1次元波。真空の保存変数はゼロ、速度は未定義です。 γ=1.4、左右(0.445,0.698,3.528)/(0.5,0,0.571)、[-5,5]、x0=0、t=1.3が一致します。 物理的な入力は一致しますが、参照カードの点値標本と保存計算の有限体積セル平均・離散格子は別表現です。
- [Euler二重膨張波：参照・比較条件](<https://hrkoyama.github.io/numerical-methods-atlas/problems/double-rarefaction/?lang=ja#references-ja>)

  左右状態(1,-2,0.4)と(1,2,0.4)、γ=1.4の低密度中央状態を持つ半解析的Riemann解が基準です。真空生成の別初期値とは区別します。
- [Euler／二重膨張波](<https://hrkoyama.github.io/numerical-methods-atlas/solutions/?lang=ja#solution-euler-double-rarefaction-ja>)
  relation: related-model
  reference_kind: semi-analytic

  半解析解 比熱比gamma>1の理想気体、平面1次元波。真空の保存変数はゼロ、速度は未定義です。 γ=1.4、左右(1,-2,0.4)/(1,2,0.4)、[0,1]、x0=0.5、t=0.15が保存プレビューと一致します。 物理的な入力は一致しますが、参照カードの点値標本と保存計算の有限体積セル平均・離散格子は別表現です。
- [湿潤床ダム崩壊：参照・比較条件](<https://hrkoyama.github.io/numerical-methods-atlas/problems/dam-break/?lang=ja#references-ja>)

  水深2と1、静止状態、g=1の湿潤河床Riemann解を半解析的に評価します。乾燥河床解の収録は、この有限体積コードの乾燥状態対応を意味しません。
- [浅水流／水深が正のダム崩壊](<https://hrkoyama.github.io/numerical-methods-atlas/solutions/?lang=ja#solution-swe-dam-break-ja>)
  relation: related-model
  reference_kind: semi-analytic

  半解析解 平坦な底面と一定の重力g。乾床は参照解のみの対応で、既存の有限体積ソルバーでは扱えません。 湿潤河床、g=1、左右水深(2,1)・速度0、x0=0.5が一致します。乾燥河床例への対応ではありません。 物理的な入力は一致しますが、参照カードの点値標本と保存計算の有限体積セル平均・離散格子は別表現です。
- [等温流体の密度ジャンプ：参照・比較条件](<https://hrkoyama.github.io/numerical-methods-atlas/problems/isothermal-jump/?lang=ja#references-ja>)

  音速1、静止した左右密度1と0.125の等温Riemann解が半解析的な基準です。Eulerのエネルギー方程式を含むSodとは別モデルです。
- [等温流／密度跳躍](<https://hrkoyama.github.io/numerical-methods-atlas/solutions/?lang=ja#solution-isothermal-jump-ja>)
  relation: related-model
  reference_kind: semi-analytic

  半解析解 p = c_s² rho、一定の音速c_s。初期密度は厳密に正とし、真空状態とエネルギー方程式はありません。 p=ρ、音速1、左右密度(1,0.125)・速度0、x0=0.5が一致します。 物理的な入力は一致しますが、参照カードの点値標本と保存計算の有限体積セル平均・離散格子は別表現です。
- [Sod衝撃波管：Godunov型更新と自己相似解：参照・検証](<https://hrkoyama.github.io/numerical-methods-atlas/code-and-data/examples/sod/?lang=ja#sod-ja-validation>)

  細格子160セルの各中心でρ,u,pと同位置・同時刻の参照値を併記。初期値も点サンプルをセル値として与える既存solverを使う。解析的な波構造を使うが、圧力根の数値評価を含み、別コードベースとの独立照合ではない。
- [Euler／Sod問題](<https://hrkoyama.github.io/numerical-methods-atlas/solutions/?lang=ja#solution-euler-sod-ja>)
  relation: related-model

## コード・検証

- [Sod衝撃波管：Godunov型更新と自己相似解](<https://hrkoyama.github.io/numerical-methods-atlas/code-and-data/examples/sod/?lang=ja>)
  availability: run

  γ=1.4、左右(ρ,u,p)=(1,0,1)/(0.125,0,0.1)、初期不連続x=0.5、t=0.2の標準問題。80/160セルの区分一定Godunov型＋HLLC＋SSPRK3を自己相似Euler解と比較する。
- [Shu–Osher：独立参照と格子収束](<https://hrkoyama.github.io/numerical-methods-atlas/validation/shu-independent/?lang=ja>)
  availability: run

  衝撃波と密度正弦波の相互作用を、同じPython実装の細格子ではなく、別に実行したAthena++の参照と照合します。
- [Brio–Wu：HLLDと保存的に粗視化した数値参照](<https://hrkoyama.github.io/numerical-methods-atlas/code-and-data/examples/brio-wu/?lang=ja>)
  availability: run

  γ=2、Bx=0.75の1次元理想MHD衝撃波管をt=0.1まで計算。HLLD＋MC＋SSPRK2の64/128セルを512セルの数値参照と比較し、密度・圧力・縦磁場・保存収支・切替回数を記録する。
- [Noh衝撃波：初期圧力ゼロの平面・円筒・球対称計算](<https://hrkoyama.github.io/numerical-methods-atlas/validation/noh-shock/?lang=ja>)
  availability: run

  初期圧力ゼロのNoh問題を、独自の小型1D有限体積コードで平面・円筒・球対称に計算します。64/128/256/512格子の全域誤差、原点過熱、衝撃位置、保存収支を測り、球で現れる境界流入の時間積分誤差を解析式と照合します。
- [Noh問題：実際の2次元Cartesian Euler計算](<https://hrkoyama.github.io/numerical-methods-atlas/validation/noh-cartesian-2d/?lang=ja>)
  availability: run

  正方形の全域で密度・2成分運動量・全エネルギーを更新する、小型の2次元Euler有限体積計算です。32²・64²・128²の3格子で厳密Noh状態からの誤差・保存収支・格子方向の影響を測ります。図は実際の2次元保存配列で、1D半径解の回転表示ではありません。
- [Sedov–Taylor点爆発：球対称の軽量検証](<https://hrkoyama.github.io/numerical-methods-atlas/validation/sedov-blast/?lang=ja>)
  availability: run

  球対称Euler方程式を半径方向の有限体積法で解く軽量例です。固定した半径0.03の領域に総エネルギー1を与え、128・256・512セルで点爆発の相似参照からの差と保存収支を測ります。図は1次元球対称データの断面表示で、2次元Cartesian計算ではありません。
- [Double Mach反射：多格子の軽量検証](<https://hrkoyama.github.io/numerical-methods-atlas/validation/double-mach-reflection/?lang=ja>)
  availability: run
