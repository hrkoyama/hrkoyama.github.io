目的から計算法を選ぶ

モデル・境界・滑らかさを確認し、候補の解説と公開コード・テストへ進みます。まず6つの代表的な目的を案内します。

衝撃波を計算したい滑らかな渦を低散逸で解きたい拡散・Poisson方程式を解きたい磁場の発散誤差を抑えたい硬い方程式を時間積分したい粒子の重力を計算したい

衝撃波を計算したい

まず非相対論・理想気体Eulerの衝撃波管から。MUSCL＋HLLCは基準となる比較候補、WENO-Zは高次再構成の候補です。CFL、正値性、境界条件を確認します。強い多次元衝撃波やMHDへの適用は別に検討してください。

拡散・Poisson方程式を解きたい

1次元三重対角系ならThomas、対称正定値系ならCG、規則格子のPoissonなら幾何マルチグリッドが候補です。境界条件と行列の性質を確認し、真の残差と格子誤差を区別します。

磁場の発散誤差を抑えたい

理想MHDではCTとGLMが比較候補です。CTの面磁場とGLMのセル中心場では離散的な発散演算子が異なります。GLMを厳密な発散ゼロの保証と扱わず、境界条件と発散ノルムを確認します。 Brio–Wu実行例は1次元の流束確認用で、CT/GLMの多次元発散制御の検証にはなりません。

粒子の重力を計算したい

孤立系のBarnes–Hutと周期境界のPMを分けて選びます。近似力を直接和と比較し、開き角・格子・境界条件を確認します。これらはGSPH流体ソルバーの代用ではありません。

候補と適用条件

Barnes–Hut八分木

孤立した3次元粒子の重力加速度をoctreeで近似する。公開例はG=1のPlummer軟化核に対し、質量単極子または同じ軟化核の完全な二次モーメント項を使い、直接和と比較する。

FFT粒子格子力

周期3次元粒子の質量をCICで格子へ割り当て、平均密度を除いたPoisson方程式をFFTで解き、格子加速度を同じCICで粒子へ戻す。公開例は連続Fourier記号 −4πG/k² とスペクトル微分を使う。

Compute shock waves

Start with nonrelativistic ideal-gas Euler shock tubes. MUSCL with HLLC provides a baseline comparison; WENO-Z is a high-order reconstruction option. Check CFL, positive states and boundaries. Strong multidimensional shocks and MHD require separate assessment.

HLLC

An approximate Riemann flux that restores the contact wave missing from HLL, improving Euler contact resolution. The released implementation is one-dimensional and perfect-gas, with Davis-type outer acoustic speeds.

FD WENO5-Z

A WENO method targeting fifth-order spatial accuracy in smooth regions while adapting stencil weights near discontinuities. The released Euler example is pointwise finite-difference WENO-Z with global Lax–Friedrichs flux splitting and SSPRK3.

Solve diffusion or Poisson equations

Consider Thomas for 1D tridiagonal systems, CG for symmetric positive-definite systems, and geometric multigrid for regular-grid Poisson problems. Check boundaries and matrix properties; distinguish true residual from discretization error.

Conjugate gradients

Solve real SPD linear systems by conjugate directions. The public example is unpreconditioned matrix-free CG for the five-point zero-Dirichlet Poisson operator on a unit square.

Control magnetic divergence errors

Compare CT and GLM for ideal MHD. Face-centered CT and cell-centered GLM use different discrete divergence operators. Compute particle gravity

Choose between isolated Barnes–Hut and periodic particle–mesh gravity. Compare approximate forces with direct sums; check opening angle, grid and boundaries. These are not GSPH fluid solvers.

Candidates and conditions

Barnes–Hut octree

Approximate isolated 3D particle gravity with an octree. The public example uses G=1 and a Plummer-softened kernel, with a monopole or the same kernel's full second-moment term, compared with direct summation.

Explanation Related code Related tests Conditions, references & all files

FFT particle–mesh forces

Deposit periodic 3D particle mass by CIC, FFT-solve Poisson after removing mean density, and interpolate acceleration back with matched CIC. The example uses the continuum Fourier symbol −4πG/k² and spectral derivatives.

Explanation Related code Related tests Conditions, references & all files

Run and validate fixed inputs

  • Barnes–Hut: 192 particles against direct summation
  • Periodic PM particles: mass, internal force and mesh field
