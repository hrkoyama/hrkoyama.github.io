磁場の発散誤差を抑えたい

理想MHDではCTとGLMが比較候補です。CTの面磁場とGLMのセル中心場では離散的な発散演算子が異なります。GLMを厳密な発散ゼロの保証と扱わず、境界条件と発散ノルムを確認します。 Brio–Wu実行例は1次元の流束確認用で、CT/GLMの多次元発散制御の検証にはなりません。 同じ連続Orszag–Tang初期場・終了時刻・CFLのCT／GLM比較と、独立Athena++照合へ進めます。採用GLMはch=3、κ=0.18 ch nの格子依存減衰で、nativeのdiv B演算子・実ステップ数は異なります。GLM Fourier例は制約診断です。

Control magnetic divergence errors

Compare CT and GLM for ideal MHD. Face-centered CT and cell-centered GLM use different discrete divergence operators. GLM is not an exact zero-divergence guarantee; inspect boundaries and divergence norms. The Brio–Wu run checks one-dimensional fluxes; it does not validate multidimensional CT/GLM divergence control. Compare CT/GLM for the same continuous Orszag–Tang data, final time and CFL, with independent Athena++ references. The adopted GLM has ch=3 and grid-dependent damping κ=0.18 ch n; native div B operators and actual step counts differ. The GLM Fourier example is a constraint diagnostic.
